## v1 대비 변경점

v1에서는 사진 자체엔 아무 숫자도 없이, 도장 옆에 숫자를 "따로 인쇄해서 붙이는" 방식이었다. 그러면 참가자가 사진을 찾기만 하면 숫자는 바로 보여서 퍼즐이 아니라 라벨 읽기가 된다.

v2는 잠금해제 숫자(`52`, `19`, `36`, `07`)를 **사진 장면 안에 소품으로 자연스럽게 숨긴다.** 5장 모두 같은 규칙을 쓴다: 어딘가에 매달린 **작은 원형/사각 번호표(클레임 티켓, 옷 보관소 물표 스타일)**가 있고, 거기 숫자가 적혀 있다. 참가자는 사진을 찾은 뒤 자세히 들여다봐야 숫자를 발견한다.

5번째 사진(`photo-promise.jpg`, 약속 카드)만 예외로 **번호표가 전혀 없다** — 이건 의도된 서사 장치다(반납 대상이 아닌 유일한 원본이라는 뜻). 절대 5번에는 번호표나 숫자를 넣지 않는다.

기존 `assets/stage-02/photo-*.jpg` 5개 파일을 덮어쓴다. 파일명은 v1과 동일.

## 공통 지침

- 세로 사진, 비율 4:5
- 인쇄용 고해상도 (1600×2000px 이상), JPG
- 사실적인 스냅샷 사진 느낌 — 일러스트/AI 티 나지 않게
- 사람이 나오는 사진(1, 2, 3번)은 얼굴이 특정되지 않게 뒷모습/옆모습/흐림 처리
- 번호표는 **찾는 데 5~10초 정도 걸리는 난이도**로: 화면 정중앙에 크게 두지 말고, 프레임 안쪽 자연스러운 위치(손에 든 것, 매달린 것, 걸려 있는 것)에 배치. 너무 작아서 인쇄해도 안 보이면 안 되고, 너무 커서 한눈에 보이면 안 됨
- 번호표에 적히는 숫자 외에 다른 글자·로고는 넣지 않는다 (숫자만, 다른 텍스트 없이)
- 번호표 모양/재질은 5장이 서로 통일감 있게: 작은 원형 또는 사각형 종이/나무/가죽 태그, 끈이나 클립으로 매달린 형태

## 파일별 생성 프롬프트

### 1. `assets/stage-02/photo-success.jpg` — 성공한 사람 (번호표: `52`)
```
시상식이나 졸업식 같은 실내 자리에서, 한 사람이 트로피나 상장을 들고 있는 순간을 찍은 듯한 사진. 그 사람은 뒷모습이거나 얼굴이 흐릿하게 보여서 누군지 특정되지 않게. 배경엔 박수치는 사람들이 흐릿하게 보임. 따뜻한 오후 실내 조명, 살짝 아마추어스러운 휴대폰 사진 구도.
트로피 손잡이나 상장 리본에 작은 원형 종이 번호표가 끈으로 매달려 있고, 거기에 숫자 "52"만 손글씨나 도장체로 적혀 있음. 번호표는 눈에 띄지만 사진 정중앙은 아닌 위치에. 그 외에 다른 글자나 로고는 없음.
```

### 2. `assets/stage-02/photo-approval.jpg` — 인정받는 사람 (번호표: `19`)
```
여러 사람에게 둘러싸여 박수를 받거나 악수·어깨를 두드림 당하는 순간을 찍은 사진. 중심 인물은 뒷모습이나 옆모습으로, 얼굴이 특정되지 않게. 따뜻한 실내 조명, 손동작에 살짝 흔들림(모션블러) 느낌.
중심 인물의 옷깃이나 손목에 작은 사각 종이 번호표가 클립이나 끈으로 달려 있고, 숫자 "19"만 적혀 있음. 번호표는 살짝 흔들린 손들 사이로 보이되, 자세히 봐야 알아볼 수 있는 위치에. 그 외 다른 글자나 로고는 없음.
```

### 3. `assets/stage-02/photo-welcome.jpg` — 이달의 새 가족 (번호표: `36`)
```
노을 지는 저녁, 갓 지어진 듯한 작은 새 집 앞에서 낯선 가족이 서로 어깨동무하고 서 있는 기념사진. 마당엔 아직 조경이 안 되어 있어 새집 느낌. 사람들은 뒷모습이거나 멀리서 찍어서 얼굴이 잘 안 보이게. 따뜻하고 살짝 바랜 색감.
현관문 손잡이나 열쇠고리에 작은 나무 번호표가 매달려 있고, 숫자 "36"만 적혀 있음. 번호표는 배경 쪽 문 근처라 한눈에 안 띄고 자세히 봐야 보임. 간판이나 다른 글자는 없음.
```

### 4. `assets/stage-02/photo-checkout.jpg` — 퇴실 안내 사본 (번호표: `07`)
```
나무로 된 문에 마스킹테이프로 살짝 삐뚤게 붙어 있는 A5 크기 안내문을 클로즈업으로 찍은 사진. 종이 맨 위에 "퇴실 안내"라는 검은색 인쇄 글씨가 보이고, 그 아래 몇 줄은 흐릿해서 안 읽힘. 자연광, 약간의 반사광. 모서리가 살짝 말려있음.
안내문 한쪽 모서리에 작은 종이 번호표가 스테이플러나 클립으로 고정돼 있고, 숫자 "07"만 적혀 있음. 번호표는 안내문 텍스트보다는 작게, 모서리 쪽이라 바로 눈에 띄지 않는 위치.
```

### 5. `assets/stage-02/photo-promise.jpg` — 약속 카드 03/16 (번호표 없음)
```
나무 테이블 위에 놓인, 낡고 살짝 접힌 작은 종이 카드 한 장을 클로즈업으로 찍은 사진. 파란 볼펜 손글씨로 "03/16"과 "약속"이라고 적혀 있음. 코팅되지 않은 누렇게 바랜 종이, 도장이나 다른 표시는 없음. 옆에서 들어오는 부드러운 창문 빛, 배경은 흐릿하게.
이 사진에는 번호표나 태그, 끈, 클립 같은 것을 절대 넣지 않는다 — 다른 4장과 달리 이 카드는 아무것도 매달려 있지 않은 상태여야 한다.
```
