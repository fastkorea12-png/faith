# 02 숙소 스테이지 패키지 — 잠긴 휴대폰 (빌린 이름)

## 1. 스테이지 계약 (Stage Contract)

| 항목 | 확정 내용 |
|---|---|
| 대상 | 대학생, 팀당 3~6명 (총 5팀 동시 진행) |
| 목표 시간 | 12~18분 (중앙값 15분) |
| 현장 장소 | 숙소 문 앞 및 입구 주변 (실제 객실 내부 투숙객 동선 침범 금지) |
| 퍼즐 장르 | 디지털 포렌식 / 현장 기록 대조 / 가상 휴대폰 해킹 |
| 핵심 질문 | 세상이 붙여준 임시 이름표 속에 숨겨진 나의 진짜 정체성은 무엇인가? |
| 물리 장치 | 물리 자물쇠 없음. 대신 사진 5장을 실물로 인쇄해 숙소 주변에 게시 — 웹 갤러리는 한 번에 한 장씩만 순차 개방된다. 잠금해제 코드는 사진에 없고, 실물 인쇄본에만 붙은 **검색어 태그**를 통해 휴대폰 검색 기록에서 찾아야 한다 |
| 휴대폰 잠금 번호 | `0316` (웹 가상 키패드 전용) |
| 웹 포렌식 정답 | 실물 사진 4장(성공한 사람/인정받는 사람/이달의 새 가족/퇴실 안내 사본)에 적힌 검색어(우승/박수/환영/체크아웃)를 검색 기록에서 찾아 해당 검색결과 숫자(64/52/19/36)를 순서대로 입력해 갤러리 5장 완성(마지막 장은 검색 기록 마지막 줄로 찾는 `07`) → 도장 문구 `수정 없음` 입력으로 원본 확정 → 검색 기록 문구 `약속을 지키는 사람` 입력으로 메모 복원 |
| 결과 키워드 | `약속` (키워드 카드 02 수령) |
| 완료 코드 | `PROMISE-02` (활동 페이지 입력) |
| 핵심 반전 | 주인이 붙들었던 정체성은 ‘성공한 사람/인정받는 사람’이라는 빌린 이름표가 아니라, 결코 바뀌지 않는 ‘약속’에서 드러난다. |

> [!IMPORTANT]
> `0316`, `약속`, `PROMISE-02`는 용도가 엄격히 구분된다. `0316`은 웹 가상 휴대폰을 열 때만 사용하는 암호이고, `약속`은 최종 05 예배당에서 조합할 실물 키워드 카드이며, `PROMISE-02`만 활동 페이지(`activity.html`)에 입력한다.

## 2. 플레이어 경험 및 서사 개요

참가자들은 숙소 입구에서 발견된 분실 휴대폰의 잠금을 해제하고 디지털 포렌식을 수행한다.
휴대폰의 주인은 자신을 ‘성공한 사람’, ‘인정받는 사람’이라고 여러 기록에 써두었다. 알림과 갤러리만 보면 그중 하나가 진짜 이름처럼 보인다. 그러나 숙소 문 앞 안내문과 현장 증거 카드를 대조하면 이 두 이름은 행사장마다 바꿔 부친 **임시 이름표**이며, 유일하게 수정되지 않은 진짜 원본은 3월 16일의 **약속 카드**임이 드러난다.

### 다중 단서 대조 체계
1. **잠금화면 알림**: 암호 힌트("약속한 날은 문 앞 안내문에 있다", "비밀번호 형식은 `MMDD`").
2. **현장 안내문**: `약속 카드 수령일 03/16`, `퇴실 안내 11:13`.
3. **벽면 실물 사진 5장**: 숙소 주변에 순서 무관하게 게시된 5장의 실물 사진(성공한 사람 / 인정받는 사람 / 이달의 새 가족 / 퇴실 안내 사본 / 약속 카드). 사진 자체(디지털 파일)에는 어떤 숫자도 없다. 대신 실물 인쇄본에만 작은 **검색어 태그**가 붙어 있다(성공한 사람=`우승`, 인정받는 사람=`박수`, 이달의 새 가족=`환영`, 퇴실 안내 사본=`체크아웃`; 약속 카드에는 태그 없음 — 반납 대상이 아니라는 서사 장치). 웹 화면은 언제나 "다음 사진 이름"만 알려주므로, 참가자는 그 이름의 실물 사진을 찾아 검색어 태그를 확인해야 한다.
4. **디지털 포렌식**: `0316`으로 휴대폰을 연 후, 벽면 실물 사진에서 확인한 검색어(우승/박수/환영/체크아웃)를 휴대폰 검색 기록 앱에서 찾아, 그 항목에 뜨는 "검색결과 N건"의 숫자(64/52/19/36)를 순서대로 입력해 갤러리 5장을 완성한다(첫 장도 예외 없이 검색어가 필요하며, 마지막 장은 검색어 태그 없이 검색 기록 마지막 줄과 같은 문구 `약속을 지키는 사람`의 검색결과 `07`로 연다). 검색 기록에는 실제 코드가 있는 항목 외에 서사용 미끼 문구도 여러 개 섞여 있어, 태그 없이는 정답을 특정할 수 없다. 이어 도장 문구 `수정 없음`을 그대로 입력해 원본을 확정하면 메모 앱이 열리고, 검색 기록 마지막 줄의 문구 `약속을 지키는 사람`을 입력해 메모를 복원하면 최종 키워드 `약속`과 완료 코드 `PROMISE-02`를 확인한다.

## 3. 팀 분업 구조 & 5팀 동시 운영 사양

5개 팀(A~E조)이 숙소 복도 주변에서 병목 없이 포렌식을 진행하도록 역할을 분담한다.

| 역할 | 담당 행동 | 반드시 공유할 정보 |
|---|---|---|
| 알림 분석관 | 가상 휴대폰 화면 접속(`game.html?stage=name`), 잠금화면 알림 2개 해독 | "약속한 날은 문 앞 안내문에", 암호 형식 `MMDD` |
| 현장 감식관 A | 숙소 문 앞 안내문 및 퇴실 시각 확인 | `약속 카드 수령일 03/16`, `퇴실 안내 11:13` (시각 배제) |
| 현장 감식관 B | 숙소 주변에 게시된 실물 사진 5장을 찾아 검색어 태그를 확인 | 웹이 요청하는 "다음 사진"의 실물 위치와 검색어 |
| 포렌식 검증관 | 팀 포렌식 기록지 작성, `0316` 입력 및 순차 코드 입력, 원본 확정, 메모 복원 | `0316` 입력, 코드 4개(순서대로), 도장 문구, 검색 기록 문구, 최종 키워드(`약속`) 및 코드(`PROMISE-02`) 회수 |

### 5팀 동시 운영 독립 키트 및 배치
- **독립 현장 증거 키트**: 5개 팀의 실물 사진 세트(안내문 포함 6종)는 팀 라벨(A~E)과 서로 다른 흑백 패턴 테두리로 구분된다.
- **실물 사진 부착 위치**: 숙소 문 외부 벽면 3~8m 범위 내에 5개 팀의 사진 5장씩을 1m 간격으로 순서 무관하게 분산 배치하여 팀 간 엿보기나 병목을 예방한다. 순서는 웹 화면의 코드 체인이 강제하므로 실물 배치 자체는 뒤섞여 있어도 무방하다.

## 4. 현장 단서 및 퍼즐 메카니즘 상세

### 4.1 제공 단서 세트

1. **가상 휴대폰 잠금화면 알림**:
   - 알림 1 (엄마): `"약속한 날은 문 앞 안내문에 적어두었다."`
   - 알림 2 (룸메이트): `"비밀번호 형식은 월일 4자리 MMDD이다."`

2. **숙소 문 앞 안내문**:
   - `숙소 문 앞 안내문`: `약속 카드 수령일 03/16`, `퇴실 안내 11:13`

3. **벽면 실물 사진 5장** (웹 갤러리와 동일한 이미지를 인쇄, 도장 문구와 검색어 태그를 인쇄 시에만 추가— 사진 파일 자체엔 없음):
   | 순서 | 사진 | 도장 문구(인쇄) | 검색어 태그(인쇄) | 검색 기록에서 찾을 검색결과 숫자 |
   |---|---|---|---|---|
   | 1 | 성공한 사람 | 임시 발급 · 반납 대상 | `우승` | `64` |
   | 2 | 인정받는 사람 | 임시 발급 · 반납 대상 | `박수` | `52` |
   | 3 | 이달의 새 가족 | 임시 발급 · 행사용 | `환영` | `19` |
   | 4 | 퇴실 안내 사본 | 사본 · 재발급 | `체크아웃` | `36` |
   | 5 | 약속 카드 03/16 | 원본 · 수정 없음 | (없음, 반납 대상이 아니므로) | `07`(검색 기록 마지막 줄 문구로 찾음) |

   1번 사진도 예외 없이 검색어·코드를 확인해야 갤러리에 들어간다(휴대폰 잠금 해제 시 자동으로 채워주지 않는다) — 그래야 참가자가 첫 장부터 현장에 나가야 할 이유가 생기고, 웹 화면만 확대해 코드를 훔쳐볼 수 있는 사진이 하나도 남지 않는다. 5번 사진에 검색어 태그가 없는 건 실수가 아니라 "이것만 반납 대상이 아니다"라는 반전을 사진만 보고도 눈치채게 하려는 의도다.

4. **팀 포렌식 기록지**:
   - 사진 순서 / 도장 상태 / 숫자 기록란.

### 4.2 암호 추론 과정
- `성공한 사람`, `인정받는 사람` $\rightarrow$ 날짜가 아니며 뒷면 도장이 `임시 발급`이므로 배제.
- `11:13` $\rightarrow$ 숫자지만 `퇴실 안내` 시각이며 MMDD 날짜가 아니므로 배제.
- `03/16` $\rightarrow$ `약속 카드 수령일`이며 MMDD 형식으로 변환 가능한 유일한 원본 날짜.
- **휴대폰 암호** = `03` (월) + `16` (일) = $\mathbf{0316}$

## 7. QR 배치 및 현장 동선

- **QR 위치**: 숙소 진입로 입구 안내판
- **QR 접속 URL**: `game.html?stage=name`
- **동선 이동**:
  1. 숙소 진입로에서 QR 스캔 후 가상 휴대폰 화면 진입.
  2. 현장 감식관들이 문 앞 안내문을 확인해 `0316`을 알아낸다.
  3. 포렌식 검증관이 `0316`을 입력해 휴대폰을 연다(첫 사진도 자동으로 채워지지 않고, 화면은 "다음 사진: 성공한 사람"만 알려준다).
  4. 화면이 알려주는 "다음 사진 이름"을 보고 현장 감식관들이 벽에서 그 실물 사진을 찾아 적힌 검색어 태그를 읽는다.
  5. 포렌식 검증관이 그 검색어를 휴대폰 검색 기록 앱에서 찾아 검색결과 숫자를 웹에 입력 → 다음 사진이 갤러리에 추가됨. 4~5를 반복해 5장을 모두 확보.
  6. 갤러리 완성 후 도장 문구 `수정 없음`을 그대로 입력해 원본을 확정.
  7. 검색 기록 마지막 줄의 문구 `약속을 지키는 사람`을 입력해 메모 복원.
  8. 화면에 나온 키워드 `약속`과 완료 코드 `PROMISE-02` 확인.
  9. 진행자에게 키워드 카드 02(`약속`) 수령 후 활동 페이지(`activity.html`)에 `PROMISE-02` 입력 및 남은 미완수 01~04 스테이지로 비선형 자유 이동 (4개 완수 후 05 예배당 결집).

## 8. 자물쇠 및 완료 코드 처리 (Lock & Code Handling)

- **물리 자물쇠**: 없음 (가상 휴대폰 포렌식 진행). 대신 실물 사진 4장의 코드를 순서대로 입력해야 갤러리가 완성된다.
- **올바른 진행 절차**:
  1. 현장 단서 대조로 산출한 `0316`을 웹 가상 키패드에 입력.
  2. 휴대폰 해제 후, 다음 사진 이름에 맞는 실물 사진을 찾아 검색어 태그(우승→박수→환영→체크아웃)를 확인하고, 검색 기록에서 그 단어를 찾아 검색결과 숫자(`64`→`52`→`19`→`36`)를 순서대로 입력. 마지막 장은 검색 기록 마지막 줄 문구로 찾은 `07`.
  3. 5장이 모두 모이면 도장 문구 `수정 없음`을 입력해 원본을 확정.
  4. 메모 앱에서 `약속을 지키는 사람`을 입력해 메모를 복원하면 최종 키워드 `약속`과 완료 코드 `PROMISE-02`가 출력됨.
  5. `0316`과 사진 코드들은 웹 가상 휴대폰 전용이고, 활동 페이지에는 `PROMISE-02`만 입력함.

## 9. 웹 화면 구현 사양 및 상태 전이

### 웹 상태 전이 (State Transitions)
1. `S0_LOCKED`: 잠금화면, 알림 배너 2개 활성화.
2. `S1_NOTICE`: 알림 상세보기 (엄마: 문 앞 기록, 룸메이트: MMDD 형식).
3. `S2_KEYPAD`: 암호 키패드 (`0316` 입력 시 `S3_GALLERY` 이동. 첫 사진도 자동 확보되지 않는다).
4. `S3_GALLERY`: 사진 갤러리(좌우 스와이프로 열람). 확보된 사진은 실사로, 남은 자리는 🔒로 표시. 다음 사진 이름과 검색결과 숫자 입력 폼을 제시(사진 자체엔 힌트 없음, 검색 기록 앱에서 확인). 오답 3회 시 10초 잠금.
5. `S4_ORIGINAL`: 5장 모두 확보 시 도장 문구 입력 폼 노출 (`수정 없음` 입력 시 `S5_MEMO` 해금). 오답 3회 시 10초 잠금.
6. `S5_MEMO`: 메모 앱, 검색 기록 문구(`약속을 지키는 사람`) 입력 폼. 오답 3회 시 10초 잠금.
7. `S6_SOLVED`: 키워드 `약속` 및 완료 코드 `PROMISE-02` 공개.

### 오답 피드백 문구
- `1113` 입력 시: `"그 숫자는 날짜가 아니라 퇴실 '시각'입니다. 약속한 날짜를 찾으세요."`
- 사진 코드 오답 시: `"그 숫자가 아닙니다. 사진 도장을 다시 확인하십시오."` (3회 오답마다 10초 잠금)
- 도장 문구 오답 시: `"많이 찍힌 기록이 원본이라는 뜻은 아닙니다. 다섯 장의 도장 문구를 다시 대조하십시오."`
- 메모 문구 오답 시: `"이 이름들이 아닙니다. 검색 기록의 가장 최근 문구를 그대로 옮겨 적으십시오."`

## 10. 진행자 3단계 힌트 가이드 (3-Tier Hint Guide)

1. **시선 (Tier 1)**: `"가상 휴대폰의 알림 2개에서 단서 장소(문 앞 안내문)와 암호 형식(MMDD)을 확인하세요."`
2. **대조 (Tier 2)**: `"숙소 문 앞 기록에서 11:13(퇴실 시각)과 이름표(임시 발급)를 제외하고, '약속 카드 수령일' 날짜를 MMDD 형식으로 변환하세요. 휴대폰을 열면 화면이 다음 사진 이름을 알려주니, 벽에서 그 사진을 찾아 적힌 검색어 태그를 확인하세요."`
3. **행동 (Tier 3)**: `"0316 입력 후 벽면 사진 성공한 사람(검색어 '우승') → 인정받는 사람(검색어 '박수') → 이달의 새 가족(검색어 '환영') → 퇴실 안내 사본(검색어 '체크아웃') 순서로 찾아, 각 검색어를 휴대폰 검색 기록에서 찾은 검색결과 숫자(64 → 52 → 19 → 36)를 입력하세요. 5장이 모두 모이면 도장 문구 '수정 없음'을 입력해 원본을 확정하고, 검색 기록 마지막 줄 '약속을 지키는 사람'을 입력해 메모를 복원하세요."`

## 11. 회차별 리셋 체크리스트 (Reset Checklist)

- [ ] 숙소 문 앞 안내문 5부 및 실물 사진 25장이 해당 위치에 정상 게시되어 있는지 점검.
- [ ] 각 실물 사진의 도장 문구가 선명하게 인쇄되어 있는지 확인.
- [ ] 성공한 사람/인정받는 사람/이달의 새 가족/퇴실 안내 사본 4장에 검색어 태그(우승/박수/환영/체크아웃)가 정확히 인쇄되어 있는지 확인 — 약속 카드에는 태그가 없어야 함.
