# 02 숙소 스테이지 패키지 — 잠긴 휴대폰 (빌린 이름)

## 1. 스테이지 계약 (Stage Contract)

| 항목 | 확정 내용 |
|---|---|
| 대상 | 대학생, 팀당 3~6명 (총 5팀 동시 진행) |
| 목표 시간 | 12~18분 (중앙값 15분) |
| 현장 장소 | 숙소 문 앞 및 입구 주변 (실제 객실 내부 투숙객 동선 침범 금지) |
| 퍼즐 장르 | 디지털 포렌식 / 현장 기록 대조 / 가상 휴대폰 해킹 |
| 핵심 질문 | 세상이 붙여준 임시 이름표 속에 숨겨진 나의 진짜 정체성은 무엇인가? |
| 물리 장치 | 물리 자물쇠 없음 (웹 가상 휴대폰 해킹 스테이지) |
| 휴대폰 잠금 번호 | `0316` (웹 가상 키패드 전용) |
| 웹 포렌식 정답 | 원본 사진 선택 (`약속 카드 03/16`) $\rightarrow$ 메모 앱 삭제선 복원 |
| 결과 키워드 | `약속` (키워드 카드 02 수령) |
| 완료 코드 | `PROMISE-02` (활동 페이지 입력) |
| 핵심 반전 | 주인이 붙들었던 정체성은 ‘성공한 사람/인정받는 사람’이라는 빌린 이름표가 아니라, 결코 바뀌지 않는 ‘약속’에서 드러난다. |

> [!IMPORTANT]
> `0316`, `약속`, `PROMISE-02`는 용도가 엄격히 구분된다. `0316`은 웹 가상 휴대폰을 열 때만 사용하는 암호이고, `약속`은 최종 05 예배당에서 조합할 실물 키워드 카드이며, `PROMISE-02`만 활동 페이지(`activity.html`)에 입력한다.

## 2. 플레이어 경험 및 서사 개요

참가자들은 숙소 입구에서 발견된 분실 휴대폰의 잠금을 해제하고 디지털 포렌식을 수행한다.
휴대폰의 주인은 자신을 ‘성공한 사람’, ‘인정받는 사람’이라고 여러 기록에 써두었다. 알림과 갤러리만 보면 그중 하나가 진짜 이름처럼 보인다. 그러나 숙소 문 앞 안내문과 현장 증거 카드를 대조하면 이 두 이름은 행사장마다 바꿔 부친 **임시 이름표**이며, 유일하게 수정되지 않은 진짜 원본은 3월 16일의 **약속 카드**임이 드러난다.

### 다중 단서 대조 체계
1. **잠금화면 알림**: 암호 힌트("약속한 날은 문 앞 안내문에 있다", "비밀번호 형식은 `MMDD`").
2. **현장 안내문 & 증거 카드**: `약속 카드 수령일 03/16` (뒷면: `원본/수정 없음`), `임시 이름표 2종` (뒷면: `임시 발급/반납 대상`), `퇴실 안내 11:13`.
3. **디지털 포렌식**: `0316`으로 휴대폰을 연 후, 사진 갤러리에서 `약속 카드`를 원본으로 선택하면 메모 앱이 열리고, 두 가짜 이름이 지워진 편집 이력 끝에 최종 키워드 `약속`과 완료 코드 `PROMISE-02`를 확인한다.

## 3. 팀 분업 구조 & 5팀 동시 운영 사양

5개 팀(A~E조)이 숙소 복도 주변에서 병목 없이 포렌식을 진행하도록 역할을 분담한다.

| 역할 | 담당 행동 | 반드시 공유할 정보 |
|---|---|---|
| 알림 분석관 | 가상 휴대폰 화면 접속(`game.html?stage=name`), 잠금화면 알림 2개 해독 | "약속한 날은 문 앞 안내문에", 암호 형식 `MMDD` |
| 현장 감식관 A | 숙소 문 앞 안내문 및 퇴실 시각 확인 | `약속 카드 수령일 03/16`, `퇴실 안내 11:13` (시각 배제) |
| 현장 감식관 B | 숙소 주변 분리 배치된 이름표/약속 카드 뒷면 도장 상태 확인 | 이름표 뒷면 `임시/반납`, 약속 카드 뒷면 `원본/수정 없음` |
| 포렌식 검증관 | 팀 포렌식 기록지 작성, `0316` 입력 및 사진 원본 선택, 메모 복원 | `0316` 입력, 원본 사진 선택, 최종 키워드(`약속`) 및 코드(`PROMISE-02`) 회수 |

### 5팀 동시 운영 독립 키트 및 배치
- **독립 현장 증거 키트**: 5개 팀의 현장 증거 카드(안내문, 이름표 2종, 약속 카드)는 팀 라벨(A~E)과 서로 다른 흑백 패턴 테두리로 구분된다.
- **증거 카드 부착 위치**: 숙소 문 외부 벽면 3~8m 범위 내에 5개 팀의 증거 키트를 1m 간격으로 분산 배치하여 팀 간 엿보기나 병목을 예방한다.

## 4. 현장 단서 및 퍼즐 메카니즘 상세

### 4.1 제공 단서 세트

1. **가상 휴대폰 잠금화면 알림**:
   - 알림 1 (엄마): `"약속한 날은 문 앞 안내문에 적어두었다."`
   - 알림 2 (룸메이트): `"비밀번호 형식은 월일 4자리 MMDD이다."`

2. **숙소 문 앞 안내문 및 증거 카드**:
   - `숙소 문 앞 안내문`: `약속 카드 수령일 03/16`, `퇴실 안내 11:13`
   - `임시 이름표 A`: `성공한 사람` (뒷면: `임시 발급 / 반납 대상`)
   - `임시 이름표 B`: `인정받는 사람` (뒷면: `임시 발급 / 반납 대상`)
   - `약속 카드`: `수령일 03/16` (뒷면: `원본 / 수정 없음`)

3. **팀 포렌식 기록지**:
   - 후보 명칭 / 기록 종류 / 상태(임시 vs 원본) / 암호 변환(MMDD) 판정표.

### 4.2 암호 추론 과정
- `성공한 사람`, `인정받는 사람` $\rightarrow$ 날짜가 아니며 뒷면 도장이 `임시 발급`이므로 배제.
- `11:13` $\rightarrow$ 숫자지만 `퇴실 안내` 시각이며 MMDD 날짜가 아니므로 배제.
- `03/16` $\rightarrow$ `약속 카드 수령일`이며 MMDD 형식으로 변환 가능한 유일한 원본 날짜.
- **휴대폰 암호** = `03` (월) + `16` (일) = $\mathbf{0316}$

## 7. QR 배치 및 현장 동선

- **QR 위치**: 숙소 진입로 입구 안내판
- **QR 접속 URL**: `game.html?stage=name`
- **동선 이동**:
  1. 숙소 진입로에서 QR 스캔 후 가상 휴대폰 화면 진입.
  2. 현장 감식관들이 문 앞 안내문과 주변 이름표/약속 카드를 탐색.
  3. `03/16`을 `0316`으로 변환해 가상 키패드에 입력.
  4. 갤러리에서 `약속 카드` 원본 사진을 선택하고 메모 앱 해금.
  5. 화면에 나온 키워드 `약속`과 완료 코드 `PROMISE-02` 확인.
  6. 진행자에게 키워드 카드 02(`약속`) 수령 후 활동 페이지(`activity.html`)에 `PROMISE-02` 입력 및 남은 미완수 01~04 스테이지로 비선형 자유 이동 (4개 완수 후 05 예배당 결집).

## 8. 자물쇠 및 완료 코드 처리 (Lock & Code Handling)

- **물리 자물쇠**: 없음 (가상 휴대폰 포렌식 진행).
- **올바른 진행 절차**:
  1. 현장 단서 대조로 산출한 `0316`을 웹 가상 키패드에 입력.
  2. 휴대폰 해제 후 사진 갤러리에서 `약속 카드`를 원본으로 선택.
  3. 메모 앱이 해금되면 최종 키워드 `약속`과 완료 코드 `PROMISE-02`가 출력됨.
  4. `0316`은 웹 가상 키패드 전용이고, 활동 페이지에는 `PROMISE-02`만 입력함.

## 9. 웹 화면 구현 사양 및 상태 전이

### 웹 상태 전이 (State Transitions)
1. `S0_LOCKED`: 잠금화면, 알림 배너 2개 활성화.
2. `S1_NOTICE`: 알림 상세보기 (엄마: 문 앞 기록, 룸메이트: MMDD 형식).
3. `S2_KEYPAD`: 암호 키패드 (`0316` 입력 시 `S3_PHOTO` 이동).
4. `S3_PHOTO`: 사진 갤러리 (성공 이름표, 인정 이름표, 약속 카드 사진 3장 표시).
5. `S4_COMPARE`: `약속 카드` 원본 사진 선택 시 `S5_MEMO` 해금.
6. `S5_MEMO`: 메모 앱 복원 (삭제된 빌린 이름들과 최종 고백 문장).
7. `S6_SOLVED`: 키워드 `약속` 및 완료 코드 `PROMISE-02` 공개.

### 오답 피드백 문구
- `1113` 입력 시: `"그 숫자는 날짜가 아니라 퇴실 '시각'입니다. 약속한 날짜를 찾으세요."`
- 이름표 사진 선택 시: `"반복해서 노출된 이름이 원본은 아닙니다. 사진의 상태 도장(임시 vs 원본)을 확인하세요."`

## 10. 진행자 3단계 힌트 가이드 (3-Tier Hint Guide)

1. **시선 (Tier 1)**: `"가상 휴대폰의 알림 2개에서 단서 장소(문 앞 안내문)와 암호 형식(MMDD)을 확인하세요."`
2. **대조 (Tier 2)**: `"숙소 문 앞 기록에서 11:13(퇴실 시각)과 이름표(임시 발급)를 제외하고, '약속 카드 수령일' 날짜를 MMDD 형식으로 변환하세요."`
3. **행동 (Tier 3)**: `"약속 카드 수령일 03/16을 네 자리 숫자로 바꿔 '0316'을 입력하세요. 휴대폰이 열리면 사진 갤러리에서 '약속 카드'를 선택해 메모를 복원하세요."`
