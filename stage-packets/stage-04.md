# 04 길 스테이지 패키지 — 되돌아가는 길 (돌아갈 수 있었던 길)

## 1. 스테이지 계약 (Stage Contract)

| 항목 | 확정 내용 |
|---|---|
| 대상 | 대학생, 팀당 3~6명 (총 5팀 동시 진행) |
| 목표 시간 | 12~18분 (목표 중앙값 15분) |
| 현장 장소 | 산책로, 복도, 또는 네 표식을 순서 없이 둘 수 있는 야외/실내 길 |
| 퍼즐 장르 | 분담 기억 미로 / 웹 루프 기록 탈출 / 역발상 문장 조합 / 방향 자물쇠 |
| 핵심 질문 | 편안했던 과거나 익숙한 출발점으로 돌아갈 수 있는 기회가 있다면, 우리는 되돌아가야 하는가? |
| 물리 장치 | 없음 (웹 방향 자물쇠로 대체 — 방향 하드웨어 조달 없이 화면에서 직접 입력) |
| 방향 자물쇠 정답 | `오른쪽 → 위 → 왼쪽 → 위` (웹 방향 자물쇠 입력) |
| 완성 문장 순서 | `돌아갈 수 있었지만` (A) $\rightarrow$ `그 길을 떠나` (B) $\rightarrow$ `더 나은 본향을` (C) $\rightarrow$ `사모하였다` (D) |
| 결과 키워드 | `더 나은 본향` (키워드 카드 04 수령) |
| 완료 코드 | `BETTER-04` (활동 페이지 입력) |
| 핵심 반전 | 첫 3개 표식의 화살표를 "가야 할 새 길"로 보던 편견이 마지막 표식의 문구("표식은 목적지가 아니라 지나온 선택의 기록이다")로 뒤집히며, 문장 조각의 순서대로 홈을 읽는 역발상이 일어난다. |

> [!IMPORTANT]
> 04는 02(가상 휴대폰)와 같은 예외에 해당한다 — 방향 자물쇠 자체가 물리 하드웨어 없이 웹 화면 안에서 완결된다. 이미 루프 탐색·장면 카드·문장 조각 조합으로 현장 물리 활동이 충분해서, 마지막 방향 입력만 웹으로 옮겨도 스테이지의 물리성이 사라지지 않는다. 완성 문장 순서(`오른쪽 → 위 → 왼쪽 → 위`)를 화면의 방향 자물쇠 UI에 그대로 입력하면 즉시 완료 코드 `BETTER-04`가 확인된다. 키워드 `더 나은 본향`은 05 예배당용으로 웹 사건 수첩에 자동 수집된다.

## 2. 플레이어 경험 및 서사 개요

참가자들은 04 길 지대에 도착한다. 웹 화면(`game.html?stage=road`)은 단순 문제지가 아니라 **루프 기록 장치**로 작동한다.
팀은 길에 흩어진 4개의 현장 표식(A 문, B 눈, C 발자국, D 별)을 분담하여 각자 20초간 관찰한다. 각 표식에는 기억해야 하는 문구와 작은 방향 홈이 인쇄되어 있다.

### 기억 미로 및 역발상 서사 구조
1. **분담 기억 & 루프 통과**: 4명의 팀원이 각자 자신이 기억한 표식 문구를 바탕으로 웹 갈림길에서 `문을 떠난다`, `기억한다`, `좁은 길`, `아직 보이지 않는 곳을 택한다`를 선택한다. 오답 선택 시 루프가 발생하여 처음 갈림길로 돌아간다.
2. **문장 조각 4개 회수**: 루프를 정상 통과할 때마다 문장 조각을 회수한다:
   - `돌아갈 수 있었지만` (A 문, 방향 홈: 오른쪽)
   - `그 길을 떠나` (B 눈, 방향 홈: 위)
   - `더 나은 본향을` (C 발자국, 방향 홈: 왼쪽)
   - `사모하였다` (D 별, 방향 홈: 위)
3. **역발상 의미 전환**: 표식 D의 지침(`"표식은 가야 할 길을 가리키지 않는다. 지나온 선택을 기록한다."`)을 깨닫고, 4개 조각을 올바른 순서로 완성한 뒤 각 조각의 방향 홈을 순서대로 읽는다:
   $$\text{순서: A } (\text{오른쪽}) \rightarrow \text{B } (\text{위}) \rightarrow \text{C } (\text{왼쪽}) \rightarrow \text{D } (\text{위}) = \mathbf{\text{오른쪽 } \rightarrow \text{ 위 } \rightarrow \text{ 왼쪽 } \rightarrow \text{ 위}}$$

## 3. 팀 분업 구조 & 5팀 동시 운영 사양

5개 팀(A~E조)이 동시에 길 지대에서 표식을 조사하므로, 팀 내 역할을 나누고 토큰을 배분하여 수색을 진행한다.

| 역할 | 담당 행동 | 반드시 공유할 정보 |
|---|---|---|
| 표식 A 관찰관 (문) | A 문 표식 20초 관찰 | `열려 있다는 것과 들어가야 한다는 것은 다르다`, 회수 문장 `돌아갈 수 있었지만`, 홈: 오른쪽 |
| 표식 B 관찰관 (눈) | B 눈 표식 20초 관찰 | `본 것은 답이 아니다. 사라진 뒤 말할 수 있어야 한다`, 회수 문장 `그 길을 떠나`, 홈: 위 |
| 표식 C 관찰관 (발자국) | C 발자국 표식 20초 관찰 | `사람 수가 아니라 하나뿐인 발자국을 따른다`, 회수 문장 `더 나은 본향을`, 홈: 왼쪽 |
| 표식 D 관찰관 (별) | D 별 표식 20초 관찰 | `돌아갈 수 있다는 말은 돌아가야 한다는 뜻이 아니다. 표식은 지나온 선택의 기록이다`, 회수 문장 `사모하였다`, 홈: 위 |
| 웹 루프 기록관 | 팀원 공유 기억을 받아 웹 갈림길 조작 | 4개 정답 선택 및 루프 통과 관리 |
| 문장 배열 & 자물쇠 해제관 | 문장 4조각 완성 후 방향 독해 및 웹 방향 자물쇠 조작 | `오른쪽 → 위 → 왼쪽 → 위`를 화면에서 순서대로 입력 |

### 5팀 동시 운영 독립 키트 및 토큰 사양
- **기억 관찰 토큰 (A~D)**: 팀별로 A~D 토큰 4개를 받아 팀원들에게 배분하여 한 사람이 모든 표식을 독점 관찰하지 못하도록 관리한다.
- **표식 5세트 분산 설치**: 표식 A~D는 5개 팀의 독립 라벨(A~E)과 식별 기호(문, 눈, 발자국, 별)를 포함하여 산책로/복도 10~20m 구간에 분산 설치된다.

## 4. 현장 단서 및 퍼즐 메카니즘 상세

### 4.1 4개 현장 표식 사양

| 표식 | 식별 기호 | 20초 관찰 기억 문구 | 회수 문장 조각 | 방향 홈 | 웹 선택 지표 |
|---|---|---|---|---|---|
| 표식 A | 문 | `열려 있다는 것과 들어가야 한다는 것은 다르다.` | `돌아갈 수 있었지만` | 오른쪽 ($\rightarrow$) | `문을 떠난다` |
| 표식 B | 눈 | `본 것은 답이 아니다. 사라진 뒤 말할 수 있어야 한다.` | `그 길을 떠나` | 위 ($\uparrow$) | `기억한다` |
| 표식 C | 발자국 | `사람 수가 아니라 하나뿐인 발자국을 따른다.` | `더 나은 본향을` | 왼쪽 ($\leftarrow$) | `좁은 길` |
| 표식 D | 별 | `돌아갈 수 있다는 말은 돌아가야 한다는 뜻이 아니다. 표식은 지나온 선택의 기록이다.` | `사모하였다` | 위 ($\uparrow$) | `아직 보이지 않는 곳을 택한다` |

### 4.2 올바른 문장 완성 & 방향 자물쇠 공식
- **완성 문장**: `"돌아갈 수 있었지만 (A) / 그 길을 떠나 (B) / 더 나은 본향을 (C) / 사모하였다 (D)"`
- **방향 자물쇠 암호**: **오른쪽 ($\rightarrow$) $\rightarrow$ 위 ($\uparrow$) $\rightarrow$ 왼쪽 ($\leftarrow$) $\rightarrow$ 위 ($\uparrow$)**

## 7. QR 배치 및 현장 동선

- **QR 위치**: 길 진입로 입구 패널
- **QR 접속 URL**: `game.html?stage=road`
- **동선 이동**:
  1. 진입점에서 A~D 관찰 토큰 분배 후 QR 스캔.
  2. 표식 담당자들이 해당 표식(A~D)으로 이동해 20초간 문구 및 조각 집중 관찰.
  3. 팀 합류 후 웹 갈림길에서 정답 선택지 입력하며 루프 통과.
  4. 회수한 문장 4조각을 `"돌아갈 수 있었지만 그 길을 떠나 더 나은 본향을 사모하였다"`로 완성.
  5. 완성 문장 순서(A$\rightarrow$B$\rightarrow$C$\rightarrow$D)대로 카드의 방향 홈 독해 (`오른쪽 → 위 → 왼쪽 → 위`).
  6. 웹 화면의 방향 자물쇠 UI에 같은 순서로 방향을 눌러 즉시 완료 코드 `BETTER-04` 확인, 활동 페이지(`activity.html`)에 입력 후 남은 미완수 01~04 스테이지로 비선형 자유 이동 (4개 완수 후 05 예배당 결집).

## 8. 자물쇠 및 완료 코드 처리 (Lock & Code Handling)

- **물리 자물쇠**: 없음. 방향 자물쇠는 웹 화면 안에서 완결된다(02 가상 휴대폰과 동일한 예외).
- **올바른 진행 절차**:
  1. 현장 표식 4조각의 문장을 순서대로 완성한 후 카드 가장자리의 방향 홈 독해.
  2. 웹의 방향 자물쇠 UI에 `오른쪽 → 위 → 왼쪽 → 위`를 순서대로 클릭.
  3. 화면에 완료 코드 `BETTER-04`가 즉시 표시되고 키워드 `더 나은 본향`이 사건 수첩에 자동 수집됨.
  4. 활동 페이지(`activity.html`)에 `BETTER-04` 입력해 04 스테이지 해금.

## 9. 웹 화면 구현 사양 및 상태 전이

### 웹 상태 전이 (State Transitions)
1. `S0_BRIEFING`: 역할 A~D 지정 및 20초 관찰 규칙 안내.
2. `S1_LOOP_1`: 1차 갈림길 (`문을 떠난다` 선택 시 A조각 획득, 오답 시 루프).
3. `S2_LOOP_2`: 2차 갈림길 (`기억한다` 선택 시 B조각 획득).
4. `S3_LOOP_3`: 3차 갈림길 (`좁은 길` 선택 시 C조각 획득).
5. `S4_LOOP_4`: 4차 갈림길 (`아직 보이지 않는 곳을 택한다` 선택 시 D조각 획득).
6. `S5_ASSEMBLE`: 문장 조각 4개 완성 슬롯 및 D 표식 의미 반전 질문 제공.
7. `S6_DIRECTION`: 웹 방향 자물쇠 UI 표시(4개 방향 버튼 + 4칸 입력 슬롯). 정답 입력 시 즉시 `unlock()` 및 완료 코드 `BETTER-04` 표시, 오답 시 흔들림 피드백 후 입력 초기화.
8. `S7_COMPLETE`: 완료 코드 확인 및 활동 페이지 이동 안내.

### 오답 피드백 문구
- 익숙한 문 선택 시: `"문은 열려 있었지만 길은 제자리입니다. A 담당자의 '열림'과 '들어감'의 차이를 다시 생각해보세요."`
- 넓은 길 선택 시: `"사람의 수는 길의 증거가 아닙니다. C 담당자가 보았던 하나뿐인 발자국 모양을 따르세요."`

## 10. 진행자 3단계 힌트 가이드 (3-Tier Hint Guide)

1. **시선 (Tier 1)**: `"A~D 표식 담당자가 20초 동안 본 기억 문구를 떠올리고, 웹의 각 갈림길 선택지와 대조하세요."`
2. **대조 (Tier 2)**: `"루프를 통과해 모은 4개 조각을 자연스러운 하나의 문장으로 완성해 보세요."`
3. **행동 (Tier 3)**: `"문장은 '돌아갈 수 있었지만 / 그 길을 떠나 / 더 나은 본향을 / 사모하였다'입니다. 표식 D의 지침대로 화살표는 가야 할 길이 아니라 지나온 기록입니다. 문장 순서(A→B→C→D)대로 카드의 방향 홈을 자물쇠에 입력하세요 (오른쪽 → 위 → 왼쪽 → 위)."`
