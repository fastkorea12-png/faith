# 04 길 스테이지 패키지 — 되돌아가는 길 (돌아갈 수 있었던 길)

## 1. 스테이지 계약 (Stage Contract)

| 항목 | 확정 내용 |
|---|---|
| 대상 | 대학생, 팀당 3~6명 (5팀 순차 진행 — 한 번에 한 팀만 입장) |
| 목표 시간 | 팀당 12~18분 (목표 중앙값 15분). 5팀 순차 진행 시 회차 간 리셋(약 1~2분) 포함 총 70~100분 소요 예상 |
| 현장 장소 | **약 10인실 규모의 실내 소형 방**(침구·옷장·창문·문이 있는 일반 숙소방 등). 네 표식을 방 안의 서로 다른 사물/구역에 나눠 배치하며, 팀 간 거리가 아니라 방 안 지점 간 구분으로 "분산"을 구현한다 |
| 퍼즐 장르 | 분담 관찰 증언 대조 / 웹 매칭 검증 / 역발상 문장 조합 / 방향 자물쇠 |
| 핵심 질문 | 편안했던 과거나 익숙한 출발점으로 돌아갈 수 있는 기회가 있다면, 우리는 되돌아가야 하는가? |
| 물리 장치 | 없음 (웹 방향 자물쇠로 대체 — 방향 하드웨어 조달 없이 화면에서 직접 입력) |
| 방향 자물쇠 정답 | `오른쪽 → 위 → 왼쪽 → 위` (웹 방향 자물쇠 다이얼 입력) |
| 완성 문장 순서 | `돌아갈 수 있었지만` (A) $\rightarrow$ `그 길을 떠나` (B) $\rightarrow$ `더 나은 본향을` (C) $\rightarrow$ `사모하였다` (D) |
| 결과 키워드 | `더 나은 본향` (키워드 카드 04 수령) |
| 완료 코드 | `BETTER-04` (활동 페이지 입력) |
| 핵심 반전 | 첫 3개 표식의 화살표를 "가야 할 새 길"로 보던 편견이 마지막 표식의 문구("표식은 목적지가 아니라 지나온 선택의 기록이다")로 뒤집히며, 문장 조각의 순서대로 홈을 읽는 역발상이 일어난다. |

> [!IMPORTANT]
> 04는 02(가상 휴대폰)와 같은 예외에 해당한다 — 방향 자물쇠 자체가 물리 하드웨어 없이 웹 화면 안에서 완결된다. 이미 증언 대조·문장 조합·현장 카드 재대조로 물리 활동이 충분해서, 마지막 방향 입력만 웹으로 옮겨도 스테이지의 물리성이 사라지지 않는다. 완성 문장 순서(`오른쪽 → 위 → 왼쪽 → 위`)를 화면의 방향 자물쇠 다이얼에 그대로 입력하면 즉시 완료 코드 `BETTER-04`가 확인된다. 키워드 `더 나은 본향`은 05 예배당용으로 웹 사건 수첩에 자동 수집된다.
>
> 방향 자물쇠 UI는 실제 판매되는 방향형 콤비네이션 자물쇠(화살표 다이얼이 달린 원형 자물쇠, 예: Master Lock 1500iD 계열)의 생김새와 조작감을 그대로 본떠 만들었다 — 원형 다이얼 중앙에 진행 표시 점 4개, 상하좌우에 화살표 버튼을 배치해 실물 자물쇠를 돌리는 느낌을 웹에서 재현한다.
>
> **v2 설계 노트(2026-08-15 개정):** v1은 표식마다 이지선다 버튼을 눌러 통과하는 방식이었는데, 선택지 라벨이 정답 논리를 그대로 반복해 패턴 매칭에 가까웠고, 조각 수집 순서·문장 순서·방향 순서가 전부 A→B→C→D로 동일해 하나의 사실을 세 번 재입력하는 구조였다. v2는 표식을 순서 없이(임의 순서로) 도전하게 하고, 정답 후보를 전부 "다른 표식의 실제 증언"으로 채워 정확한 구두 전달 없이는 통과할 수 없게 했다. 문장 조각 텍스트는 카드에 인쇄하지 않고 웹에서 증언을 맞혀야만 보상으로 드러나므로, 카드를 안 읽고 웹만 눌러서는 통과되지 않는다.
>
> **v3 설계 노트(2026-08-15 재개정):** 방향 자물쇠 UI를 실제 방향형 콤비네이션 자물쇠 모양의 원형 다이얼로 다시 그렸다(상하좌우 배치 + 중앙 진행 표시). 동시에 카드를 안 읽고도 화면만으로 시행착오를 반복해 뚫는 것을 막기 위해, 4자리 입력을 3회 연속 틀리면 10초간 입력을 잠그는 잠금 로직을 추가했다(표식 증언 대조 단계의 잠금과 동일한 패턴).
>
> **v4 설계 노트(2026-08-15 3차 개정 — 장소 변경):** 실제 배정 장소가 산책로·복도가 아니라 **약 10인실 규모의 실내 방**으로 확정되어, "산책로 10~20m 분산 설치·5팀 동시 진행" 전제를 버리고 **한 팀씩 순차 입장, 방 안 네 지점 재사용** 구조로 다시 짰다. 04의 퍼즐 콘텐츠(증언 문구·문장 조각·방향값·완료 코드)는 팀마다 다르지 않으므로(게임 로직상 전 팀 공통값), 표식 카드도 팀별로 20장을 따로 만들 필요 없이 **4장 한 세트를 그대로 재사용**한다 — 이전 팀이 나가면 카드 위치만 확인하고 다음 팀을 들인다. 자세한 배치안은 5·7·11번 참고.

## 2. 플레이어 경험 및 서사 개요

한 팀이 04 방에 입장한다(다음 팀은 이 팀이 나갈 때까지 밖에서 대기하거나 다른 스테이지를 먼저 진행한다). 웹 화면(`game.html?stage=road`)은 단순 문제지가 아니라 **증언 대조 장치**로 작동한다.
팀은 방 안 네 곳(예: 문 주변, 창가, 옷장/수납장 안, 침구 밑)에 나뉘어 배치된 현장 표식(A 문, B 눈, C 발자국, D 별)을 분담하여 각자 20초간 관찰한다. 각 표식 카드에는 **증언 문구와 방향 홈만** 인쇄되어 있다(문장 조각은 카드에 없다 — 웹에서 증언을 정확히 맞혀야만 보상으로 드러난다). 담당자는 자기 표식만 보고 다른 표식은 보지 않는다 — 좁은 방이라 서로 시야에 들어오기 쉬우므로, 카드를 봉투에 넣거나 접어 두는 등 자기 담당 외에는 우연히도 안 보이게 처리해 둔다.

### 증언 대조 및 역발상 서사 구조
1. **분담 관찰 & 증언 대조 (순서 무관)**: 4명의 팀원이 합류해 서로 자신이 관찰한 증언 문구를 정확한 표현 그대로 전달한다. 웹은 4개 표식을 동시에 제시하며 팀이 원하는 순서로 도전할 수 있다. 각 표식마다 실제 4개 표식의 증언 문구(전부 진짜 문구, 가짜 유인책 아님)가 선택지로 뜨므로, 부정확하게 전달받으면 다른 표식의 증언을 고르게 되어 통과되지 않는다. 3회 연속 오답 시 8초간 입력이 잠긴다.
2. **문장 조각 4개 확보**: 표식을 정확히 맞힐 때마다 그 표식의 문장 조각이 웹에 드러난다:
   - `돌아갈 수 있었지만` (A 문, 방향 홈: 오른쪽)
   - `그 길을 떠나` (B 눈, 방향 홈: 위)
   - `더 나은 본향을` (C 발자국, 방향 홈: 왼쪽)
   - `사모하였다` (D 별, 방향 홈: 위)
3. **문장 조합**: 4개 조각이 드러나는 순서는 팀이 표식을 맞힌 순서(임의)이므로, 팀은 자연스러운 한 문장이 되도록 스스로 순서를 판단해 배치해야 한다.
4. **역발상 의미 전환**: 문장을 완성하면 표식 D의 지침(`"표식은 가야 할 길을 가리키지 않는다. 지나온 선택을 기록한다."`)이 드러나고, 완성한 문장 순서대로 각 표식 카드의 방향 홈을 다시 확인한다:
   $$\text{순서: A } (\text{오른쪽}) \rightarrow \text{B } (\text{위}) \rightarrow \text{C } (\text{왼쪽}) \rightarrow \text{D } (\text{위}) = \mathbf{\text{오른쪽 } \rightarrow \text{ 위 } \rightarrow \text{ 왼쪽 } \rightarrow \text{ 위}}$$

## 3. 팀 분업 구조 & 5팀 순차 운영 사양

5개 팀(A~E조)이 한 팀씩 순서대로 방에 들어와 표식을 조사하므로, 팀 내 역할을 나누고 토큰을 배분하여 수색을 진행한다.

| 역할 | 담당 행동 | 반드시 공유할 정보 |
|---|---|---|
| 표식 A 관찰관 (문) | A 문 표식 20초 관찰 (다른 표식은 보지 않음) | `열려 있다는 것과 들어가야 한다는 것은 다르다`를 정확한 표현 그대로 전달 |
| 표식 B 관찰관 (눈) | B 눈 표식 20초 관찰 (다른 표식은 보지 않음) | `본 것은 답이 아니다. 사라진 뒤 말할 수 있어야 한다`를 정확한 표현 그대로 전달 |
| 표식 C 관찰관 (발자국) | C 발자국 표식 20초 관찰 (다른 표식은 보지 않음) | `사람 수가 아니라 하나뿐인 발자국을 따른다`를 정확한 표현 그대로 전달 |
| 표식 D 관찰관 (별) | D 별 표식 20초 관찰 (다른 표식은 보지 않음) | `돌아갈 수 있다는 말은 돌아가야 한다는 뜻이 아니다`를 정확한 표현 그대로 전달 |
| 웹 대조관 | 4명이 전달한 증언을 웹의 4개 표식 항목에 순서 무관하게 지목 | 어느 증언이 어느 표식(A~D)의 것인지 정확히 구분해서 전달받아야 함(부정확하면 다른 표식으로 오인되어 통과 안 됨) |
| 문장 배열 & 자물쇠 해제관 | 드러난 문장 4조각을 자연스러운 순서로 배치, 방향 재독해 및 웹 방향 자물쇠 다이얼 조작 | 완성 문장 순서대로 A~D 표식 카드를 다시 찾아 방향 홈을 읽고 `오른쪽 → 위 → 왼쪽 → 위`를 화면 다이얼에 순서대로 입력 |

> 표식 D 카드에는 `표식은 지나온 선택의 기록이다`라는 반전 문구를 인쇄하지 않는다. 이 문구는 팀이 문장 4조각을 올바른 순서로 완성한 뒤 웹 화면에 자동으로 공개되는 서사 반전이다.

### 회차별 운영 키트 및 토큰 사양
- **기억 관찰 토큰 (A~D)**: 팀이 입장하면 A~D 토큰 4개를 팀원들에게 배분하여 한 사람이 모든 표식을 독점 관찰하지 못하도록 관리한다. 팀이 나갈 때 회수해 다음 팀에게 재사용한다(1세트로 충분, 분실 대비 예비 1세트 권장).
- **표식 1세트 고정 설치, 팀마다 재사용**: 04의 증언 문구·문장 조각·방향값은 팀마다 다르지 않으므로(전 팀 공통 정답), 표식 카드 A~D 4장을 방 안에 한 번만 설치하고 5팀 모두 같은 카드를 본다. 진행자는 팀 교대 시 카드가 원래 위치·원래 봉투/은닉 상태에 그대로 있는지만 확인하면 된다(00처럼 팀별로 다른 암호를 인쇄할 필요 없음).

## 4. 현장 단서 및 퍼즐 메카니즘 상세

### 4.1 4개 현장 표식 사양

카드에는 식별 기호, 증언 문구, 방향 홈만 인쇄한다. **문장 조각은 카드에 인쇄하지 않는다** — 웹에서 증언을 정확히 맞혀야만 보상으로 드러난다.

| 표식 | 식별 기호 | 카드 인쇄 증언 문구 | 방향 홈(카드 인쇄) | 웹에서 확인되는 문장 조각 |
|---|---|---|---|---|
| 표식 A | 문 | `열려 있다는 것과 들어가야 한다는 것은 다르다.` | 오른쪽 ($\rightarrow$) | `돌아갈 수 있었지만` |
| 표식 B | 눈 | `본 것은 답이 아니다. 사라진 뒤 말할 수 있어야 한다.` | 위 ($\uparrow$) | `그 길을 떠나` |
| 표식 C | 발자국 | `사람 수가 아니라 하나뿐인 발자국을 따른다.` | 왼쪽 ($\leftarrow$) | `더 나은 본향을` |
| 표식 D | 별 | `돌아갈 수 있다는 말은 돌아가야 한다는 뜻이 아니다.` | 위 ($\uparrow$) | `사모하였다` |

웹의 증언 대조 화면은 4개 표식을 동시에 보여주며, 각 표식마다 위 4개 증언 문구 전부를 선택지로 제시한다(전부 실제 표식의 진짜 문구이며 순서는 매 세션 무작위). 팀이 정확히 전달받지 못하면 다른 표식의 증언을 고르게 되어 통과되지 않는다.

### 4.2 올바른 문장 완성 & 방향 자물쇠 공식
- **완성 문장**: `"돌아갈 수 있었지만 (A) / 그 길을 떠나 (B) / 더 나은 본향을 (C) / 사모하였다 (D)"`
- **방향 자물쇠 암호**: **오른쪽 ($\rightarrow$) $\rightarrow$ 위 ($\uparrow$) $\rightarrow$ 왼쪽 ($\leftarrow$) $\rightarrow$ 위 ($\uparrow$)**

## 5. 소형 방(약 10인실) 기준 준비물 및 소품 수량

5팀이 순차로 재사용하므로 팀별 수량이 아니라 **방 1개 고정 세트**로 준비한다.

| 준비물 | 수량 | 규격 및 용도 | 배치 위치(방 안 예시) |
|---|---:|---|---|
| 현장 표식 카드 A~D 세트 | 4장 (+예비 1세트 4장 권장) | A5 또는 A6 코팅 카드 (증언 문구+방향홈만 인쇄, 팀 라벨 불필요) | A(문): 출입문 옆 · B(눈): 창가 · C(발자국): 바닥/신발장 근처 · D(별): 높은 곳(선반·조명 근처) 등 방 안 4개 구역 |
| 카드 은닉용 봉투/파우치 | 4개 | 작은 불투명 봉투 또는 접이식 포켓 — 각 카드를 담당자만 여는 용도 | 각 카드 배치 지점 |
| 기억 관찰 토큰 세트 | 1세트(4개) + 예비 1세트 | 아크릴/목재 또는 색깔 스티커로 대체 가능 (A:문, B:눈, C:발자국, D:별) | 방 입구, 팀 입장 시 배분 후 퇴장 시 회수 |
| 길 스테이션 QR 안내판 | 1개 | A4 코팅 패널 또는 문에 부착 | 방 출입문 |
| 진행자용 타이머 | 1개 | 회차 간 리셋 시간 관리(팀당 진행 12~18분 + 리셋 1~2분) | 진행자 소지 |

## 7. QR 배치 및 현장 동선

- **QR 위치**: 방 출입문 패널
- **QR 접속 URL**: `game.html?stage=road`
- **입장 방식**: 5팀 순차 진행. 대기 중인 팀은 문 밖(또는 복도)에서 기다리거나, 비선형 자유 이동 원칙에 따라 먼저 다른 미완수 스테이지(02/03/05 등)를 진행하다가 04 차례가 되면 호출받아 들어온다. 진행자가 방 앞에서 입/퇴장을 통제한다.
- **동선 이동(팀 1개 기준)**:
  1. 진입 전 진행자가 A~D 관찰 토큰 4개 분배, 팀 입장 후 QR 스캔.
  2. 표식 담당자들이 방 안 해당 표식 위치(A~D, 순서 무관)로 흩어져 20초간 자기 표식의 증언 문구만 집중 관찰 — 봉투/파우치를 열어 확인 후 제자리에 되돌려 놓는다.
  3. 팀 합류 후 서로 증언을 정확한 표현 그대로 전달하고, 웹의 증언 대조 화면에서 4개 표식을 원하는 순서로 지목해 문장 조각을 확보.
  4. 드러난 문장 4조각을 `"돌아갈 수 있었지만 그 길을 떠나 더 나은 본향을 사모하였다"`로 스스로 순서를 판단해 완성.
  5. 웹에 드러나는 반전 문구를 확인한 뒤, 완성 문장 순서(A$\rightarrow$B$\rightarrow$C$\rightarrow$D)대로 카드의 방향 홈 재독해 (`오른쪽 → 위 → 왼쪽 → 위`).
  6. 웹 화면의 방향 자물쇠 다이얼에 같은 순서로 방향을 눌러 즉시 완료 코드 `BETTER-04` 확인, 활동 페이지(`activity.html`)에 입력.
  7. 팀 퇴장, 토큰 회수. 진행자가 카드 4장 위치·봉투 상태를 재확인(11번 체크리스트)한 뒤 다음 팀 호출.

## 8. 자물쇠 및 완료 코드 처리 (Lock & Code Handling)

- **물리 자물쇠**: 없음. 방향 자물쇠는 웹 화면 안에서 완결된다(02 가상 휴대폰과 동일한 예외). 다만 UI는 실제 방향형 콤비네이션 자물쇠 모양의 원형 다이얼로 구현한다.
- **올바른 진행 절차**:
  1. 네 표식의 증언을 웹에서 정확히 대조해 문장 조각 4개를 확보.
  2. 조각을 자연스러운 한 문장으로 배치 완성 후, 완성 문장 순서대로 카드 가장자리의 방향 홈 재독해.
  3. 웹의 방향 자물쇠 다이얼에 `오른쪽 → 위 → 왼쪽 → 위`를 순서대로 클릭.
  4. 화면에 완료 코드 `BETTER-04`가 즉시 표시되고 키워드 `더 나은 본향`이 사건 수첩에 자동 수집됨. 4자리 입력을 3회 연속 틀리면 10초간 입력이 잠긴다.
  5. 활동 페이지(`activity.html`)에 `BETTER-04` 입력해 04 스테이지 해금.

## 9. 웹 화면 구현 사양 및 상태 전이

### 웹 상태 전이 (State Transitions)
1. `S0_BRIEFING`: 역할 A~D 지정 및 20초 관찰 규칙 안내(자기 표식만 관찰, 촬영·필기 금지).
2. `S1_MATCH`: 4개 표식을 동시에 제시, 팀이 원하는 순서로 증언 대조. 각 표식마다 4개 표식의 실제 증언 문구(전부 진짜, 매 세션 무작위 순서)가 선택지로 노출. 정답 지목 시 해당 문장 조각 즉시 공개, 오답 시 흔들림 피드백(3회 연속 오답마다 8초 입력 잠김).
3. `S2_ASSEMBLE`: 4개 표식이 모두 대조되면 자동 전환. 확보된 문장 조각(대조 완료 순서, 임의)을 슬롯에 스스로 순서를 판단해 배치. 오답 시 흔들림 피드백 후 재배치.
4. `S3_REVEAL`: 문장 완성 확인 후 D 표식 의미 반전 문구를 자동 공개(퀴즈 없음, 서사 전환). "방향 자물쇠로 이동" 버튼 제공.
5. `S4_DIRECTION`: 원형 다이얼 방향 자물쇠 UI 표시(중앙 진행 표시 4칸 + 상하좌우 방향 버튼, 실제 방향형 콤비네이션 자물쇠 모양). 정답 입력 시 즉시 `unlock()` 및 완료 코드 `BETTER-04` 표시. 오답 시 흔들림 피드백 후 900ms 뒤 입력 초기화, 4자리 시도 기준 3회 연속 오답 시 10초 입력 잠김.
6. `S5_COMPLETE`: 완료 코드 확인 및 활동 페이지 이동 안내.

### 오답 피드백 문구
- 증언 대조 오답 시: `"그 증언은 다른 표식의 것입니다. 담당자에게 문구를 다시 정확히 전달받으십시오."`
- 문장 배치 오답 시: `"무엇을 떠나 무엇을 사모했는지, 자연스러운 한 문장으로 다시 읽어 보십시오."`
- 방향 자물쇠 오답 시: `"그 방향으로는 자물쇠가 열리지 않습니다. 완성한 문장 순서를 다시 떠올려 보십시오."`

## 10. 진행자 3단계 힌트 가이드 (3-Tier Hint Guide)

1. **시선 (Tier 1)**: `"A~D 표식 담당자가 20초 동안 본 증언 문구를 정확한 표현 그대로 서로에게 전달하고, 웹의 표식별 선택지와 대조하세요."`
2. **대조 (Tier 2)**: `"대조로 확보한 4개 문장 조각이 자연스러운 하나의 문장이 되는 순서를 스스로 판단해 배치해 보세요."`
3. **행동 (Tier 3)**: `"문장은 '돌아갈 수 있었지만 / 그 길을 떠나 / 더 나은 본향을 / 사모하였다'입니다. 표식 D의 지침대로 화살표는 가야 할 길이 아니라 지나온 기록입니다. 문장 순서(A→B→C→D)대로 카드의 방향 홈을 화면의 방향 자물쇠 다이얼에 입력하세요 (오른쪽 → 위 → 왼쪽 → 위)."`

## 11. 회차별 리셋 체크리스트 (Reset Checklist)

**팀마다 반복** — 좁은 방에서 5팀이 순차로 도는 구조라, 다음 팀을 들이기 전 아래를 빠르게(1~2분 목표) 확인한다.

- [ ] 방 안 4개 지점(문/창가/바닥·신발장/높은 곳)에 표식 카드 A~D가 각자 봉투·파우치 안에 원래대로 들어 있는지 확인(이전 팀이 안 넣고 나갔는지 특히 확인).
- [ ] 기억 관찰 토큰 4개(+예비 세트)가 입구에 회수·비치되어 있는지 점검.
- [ ] 이전 팀의 진행 상태가 남아 있지 않도록 웹 기기에서 `road` 스테이지를 초기화(관리자 모드의 "이 스테이지 초기화" 버튼, 또는 팀별로 각자 휴대폰으로 접속하는 구조라면 불필요).
- [ ] 웹 테스트 기기에서 방향 자물쇠 다이얼 UI가 정상 표시되고, `오른쪽→위→왼쪽→위` 입력 시 `BETTER-04`로 통과되는지 확인(물리 자물쇠/봉투 준비물 없음).
- [ ] 방 안에 이전 팀 흔적(예비 힌트 메모, 벗어둔 소지품 등)이 없는지 확인.

돌아갈 기회가 있었으나 그 과거에 안주하지 않고 더 나은 본향을 사모하며 앞으로 나아간 성경 속 순례자들의 결단을 경험하게 하는 핵심 메인 퍼즐입니다. 완료 후 남아있는 미완수 스테이지 또는 05 예배당 최종 결집으로 안내하십시오.
