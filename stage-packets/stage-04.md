# 04 길 스테이지 패키지: 돌아갈 수 있었던 길

## 스테이지 계약

| 항목 | 확정값 |
|---|---|
| 대상 | 대학생, 3~6명 1팀 |
| 목표 시간 | 12~18분(목표 중앙값 15분) |
| 현장 장소 | 비아 돌로로사 또는 네 표식을 순서 없이 둘 수 있는 길 |
| 장르 | 현장 관찰 / 분담 기억 / 루프 선택 / 문장 조합 / 방향 자물쇠 |
| 물리 장치 | 4방향 자물쇠가 달린 완료 봉투 1개 |
| 정답 방향 | `오른쪽 → 위 → 왼쪽 → 위` |
| 키워드 | `더 나은 본향` |
| 완료 코드 | `BETTER-04` |
| 마지막 의미 | 돌아갈 수 있다는 사실이 돌아가야 한다는 명령은 아니다. 익숙함을 목적지로 읽던 선택이 마지막에 뒤집힌다. |

성경 구절이나 인물 지식은 정답 조건에 포함하지 않는다. 참가자는 현장 표식의 모양·위치, 웹의 반복 기록, 팀원의 기억, 한국어 문장 연결만으로 풀 수 있어야 한다.

## 핵심 경험

웹은 정답을 묻는 문제지가 아니라 **루프 기록 장치**다. 팀은 길에 흩어진 표식 네 개를 나누어 관찰한다. 각 표식에는 한 사람이 맡아 기억해야 하는 짧은 문구와 방향 홈이 있고, 웹의 네 갈림길에서는 그 기억을 근거로 선택한다. 올바른 선택을 통과할 때마다 문장 조각을 회수한다.

마지막에는 네 조각을 다음 문장으로 배열한다.

> 돌아갈 수 있었지만 / 그 길을 떠나 / 더 나은 본향을 / 사모하였다

처음 세 갈림길 동안 참가자는 화살표를 “지금 따라갈 길”로 읽는다. 그러나 마지막 현장 표식의 문구 `표식은 목적지를 가리키지 않는다. 지나온 선택을 기록한다.`가 그 해석을 뒤집는다. 네 방향은 새 길을 고르는 지시가 아니라, 이미 선택한 문장 네 조각의 **순서를 증명하는 기록**이었다. 문장 순서대로 각 조각과 짝지어진 방향 홈을 읽으면 `오른쪽 → 위 → 왼쪽 → 위`가 된다.

이 반전은 임의 규칙이 아니다. 첫 표식의 `돌아갈 수 있다`와 마지막 표식의 `돌아가야 한다는 뜻은 아니다`가 서로 대응하고, 웹 반복 기록에도 매번 “선택”과 “기록 방향”이 별도 열로 남아 사전에 확인할 수 있다.

## 현장 준비물

- 참가자용 QR 안내판 1장
- 길 표식 A~D 각 1장(총 4장, 서로 시야가 겹치지 않는 위치에 설치)
- 표식별 문장 조각 카드 각 1장(총 4장)
- 방향 홈 또는 흑백 식별 가능한 방향 아이콘 4개
- 표식 담당 토큰 A~D 각 1개(팀원이 자신의 관찰 구역을 고르게 함)
- `기억 규칙: 촬영·필기 없이 20초 관찰 후 합류` 안내 카드 1장
- 4방향 자물쇠 1개
- 완료 봉투 1개
- 봉투 안 키워드 카드 `더 나은 본향` 1장
- 봉투 안 완료 코드 카드 `BETTER-04` 1장
- 진행자용 정답·힌트 카드 1장
- 예비 표식 세트 1부와 자물쇠 초기화 안내 1장

표식은 색만으로 구분하지 않는다. A=문, B=눈, C=발자국, D=별 모양을 함께 사용해 흑백 인쇄와 색각 차이에서도 구분되게 한다. 조각 카드의 방향은 참가자 정면 기준이 아니라 카드에 인쇄된 `위` 기준으로 판독한다.

## 현장 표식 사양

| 표식 | 설치 위치 원칙 | 20초 동안 보이는 기억 문구 | 회수 문장 조각 | 방향 홈 | 웹에서 증명하는 선택 |
|---|---|---|---|---|---|
| A 문 | 출발점에서 뒤를 돌아봐야 보이는 곳 | `열려 있다는 것과 들어가야 한다는 것은 다르다.` | `돌아갈 수 있었지만` | 오른쪽 | `문을 떠난다` |
| B 눈 | 정면 안내물 옆이 아닌 측면 | `본 것은 답이 아니다. 사라진 뒤 말할 수 있어야 한다.` | `그 길을 떠나` | 위 | `기억한다` |
| C 발자국 | 넓은 길과 좁은 길의 경계 | `사람 수가 아니라 하나뿐인 발자국을 따른다.` | `더 나은 본향을` | 왼쪽 | `좁은 길` |
| D 별 | 마지막 갈림길, 눈높이보다 약간 위 | `돌아갈 수 있다는 말은 돌아가야 한다는 뜻이 아니다. 표식은 지나온 선택의 기록이다.` | `사모하였다` | 위 | `아직 보이지 않는 곳을 택한다` |

각 표식의 문구와 조각은 같은 면에 두되, 방향 홈은 조각 가장자리에 작게 둔다. 방향만 훔쳐 읽어 자물쇠를 찍지 못하도록 네 조각을 올바른 문장으로 배열하기 전에는 읽는 순서가 생기지 않게 한다.

## 팀원별 기억 분담

1. 팀은 A~D 토큰을 나눈다. 3명 팀은 한 명이 A와 D를 맡고, 5~6명 팀은 남는 인원이 웹 기록관과 조각 관리자를 맡는다.
2. A~D 담당자는 각자 해당 표식만 20초간 본다. 촬영과 필기는 하지 않는다.
3. 합류한 뒤 웹 기록관이 갈림길 화면을 조작하되, 선택 버튼을 누르기 전에 해당 담당자가 기억 문구를 말해야 한다.
4. 오답으로 루프가 생기면 정답을 공개하지 않는다. 그 표식 담당자가 본 문구를 다시 설명하고 다른 팀원이 질문한다.
5. 조각 관리자는 회수한 카드의 문구와 방향 홈을 보관하되, 네 장이 모이기 전에는 배열을 확정하지 않는다.

이 구조의 목적은 기억력이 좋은 한 명을 시험하는 것이 아니다. 정보 소유자를 분산해 최소 네 번의 짧은 설명과 팀 토론이 발생하게 하는 것이다. 진행자는 한 사람이 모든 표식을 순회하거나 휴대폰으로 촬영하지 않도록 안내한다.

## 풀이 순서

1. QR을 열면 웹은 “네 표식은 동시에 조사해야 하며, 표식은 선택의 근거이지 정답 방향 그 자체가 아니다”라고 안내한다.
2. 팀원이 A~D 구역을 나누어 20초씩 관찰하고 합류한다.
3. 웹의 첫 갈림길에서 A 담당자의 기억을 근거로 `문을 떠난다`를 고른다. 성공하면 A 조각을 회수하라는 위치 단서가 열린다.
4. B 담당자의 기억으로 `기억한다`, C 담당자의 기억으로 `좁은 길`, D 담당자의 기억으로 `아직 보이지 않는 곳을 택한다`를 차례로 고른다.
5. 잘못 고르면 해당 갈림길의 짧은 피드백이 나온 뒤 첫 화면으로 돌아간다. 이미 얻은 조각과 반복 기록은 유지된다.
6. 네 조각을 자연스러운 문장으로 배열한다. 조사 순서와 문장 순서가 우연히 같더라도, 웹은 팀에게 각 연결어의 근거를 말하게 하고 한 번만 확인한다.
7. 마지막 D 문구를 다시 읽으면서 화살표가 “가야 할 길”이 아니라 “지나온 선택의 기록”임을 알아낸다.
8. 배열된 문장 순서대로 카드의 방향 홈을 읽어 실제 방향 자물쇠에 `오른쪽 → 위 → 왼쪽 → 위`를 한 번 입력한다.
9. 열린 봉투에서 키워드 `더 나은 본향`과 완료 코드 `BETTER-04`를 얻는다. 방향은 웹에 다시 입력하지 않는다.
10. 활동 페이지에 완료 코드만 입력한다.

## 웹 상태와 구현 계약

### 기준선 `game.js`의 현재 상태

- `road` 스테이지의 제목, 키워드, 완료 코드는 기준선과 일치한다.
- 네 갈림길, 반복 기록, 문장 조각 배열, 방향 순서 `right, up, left, up`이 구현되어 있다.
- 오답은 어느 선택이든 동일한 피드백으로 처음으로 돌아가며, 조각은 유지된다.
- 문장 조각에 방향 글자가 즉시 보이고, 문장 완성 뒤 웹 방향 패드에 방향을 다시 입력하면 웹이 완료 처리한다.
- 새로고침 시 루프, 조각, 문장 배열 상태가 유지되지 않는다.

### 통합 구현 목표

| 상태 | 웹에 보여 줄 것 | 다음 상태 |
|---|---|---|
| `briefing` | 역할 A~D, 20초 기억 규칙, 현장 표식 탐색 지시 | 팀 준비 확인 후 `loop-1` |
| `loop-1`~`loop-4` | 한 장면과 2개 선택, 누적 반복 기록, 회수한 조각 수 | 정답이면 다음 장면, 오답이면 `loop-1` |
| `assemble` | 방향을 가린 문장 조각 4개와 배열 슬롯 | 문장 확인 후 `interpret` |
| `interpret` | D 표식 문구 회상 질문과 “길/기록” 두 해석 | `기록` 선택 시 `physical-lock` |
| `physical-lock` | 문장 순서대로 카드의 홈을 읽어 실제 자물쇠를 열라는 지시 | 웹 내 방향 입력 없음 |
| `complete-instructions` | 봉투의 완료 코드를 활동 페이지에 입력하라는 안내 | 활동 페이지로 이동 |

웹은 각 성공 뒤 조각의 **회수 위치**만 알려 주고 방향은 화면에 쓰지 않는다. 진행 상태(`현재 루프`, `회수 조각`, `오답 기록`, `배열 상태`)는 세션 저장소에 보존해 우발적 새로고침 후 이어갈 수 있게 한다. 관리자 미리보기에서는 초기화 버튼을 제공하되 참가자 화면에는 노출하지 않는다.

실제 자물쇠가 정답 판정 장치이므로 웹의 현재 방향 패드와 `unlock()` 호출은 제거 대상이다. 봉투 안 `BETTER-04`가 유일한 완료 증거다.

## 실패 피드백

피드백은 1~2문장으로 즉시 보여 주고, 정답 단어를 그대로 주지 않는다.

| 실패 지점 | 짧은 피드백 |
|---|---|
| 1차: 익숙한 문 선택 | `문은 열렸지만 길은 제자리입니다. A 담당자가 “열림”과 “들어감”의 차이를 다시 말해 보세요.` |
| 2차: 빠른 길 선택 | `빠르게 보았지만 남은 기록이 없습니다. B 담당자가 표식이 사라진 뒤에도 기억한 문장을 말해 보세요.` |
| 3차: 사람이 많은 길 선택 | `사람 수는 길의 증거가 아니었습니다. C 담당자가 하나뿐이었던 모양을 설명해 보세요.` |
| 4차: 돌아갈 수 있었던 곳 선택 | `돌아갈 수는 있습니다. 그러나 D 표식은 가능과 명령을 같은 뜻으로 쓰지 않았습니다.` |
| 문장 배열 오류 | `네 조각은 모두 맞지만 연결이 끊깁니다. “무엇을 떠나 무엇을 사모했는가”를 한 문장으로 읽어 보세요.` |
| 의미 반전 오류: 길 선택 | `화살표가 목적지라면 반복 기록은 필요 없었을 겁니다. D 담당자의 마지막 문장을 다시 확인하세요.` |
| 자물쇠 실패 | `방향은 맞는 종류지만 순서가 다릅니다. 조사 순서가 아니라 완성 문장의 순서대로 홈을 읽으세요.` |
| 조각 분실·표식 훼손 | `현장 기록 하나가 누락되었습니다. 진행자에게 사건파일 복원 요청을 하세요.` |

같은 선택을 두 번 연속 틀리면 해당 담당자에게 표식을 10초 재관찰하게 한다. 세 번째에는 힌트 2를 제공해 무의미한 반복을 막는다.

## 힌트 3단계

- **힌트 1 — 시선:** `웹 선택지보다 A~D 표식의 짧은 문구를 먼저 떠올리세요. 네 사람의 기억이 각각 한 갈림길을 담당합니다.`
- **힌트 2 — 대조:** `각 표식의 문구를 같은 번호의 갈림길 두 선택과 대조하세요. 조각이 다 모이면 조사 순서가 아니라 자연스러운 한 문장 순서로 놓으세요.`
- **힌트 3 — 행동 직전:** `문장은 “돌아갈 수 있었지만 / 그 길을 떠나 / 더 나은 본향을 / 사모하였다”입니다. D 표식대로 화살표를 새 길이 아닌 지나온 기록으로 보고, 이 문장 순서의 카드 홈을 자물쇠에 입력하세요.`

힌트 3도 방향 네 개를 직접 읽어 주지는 않는다. 카드가 없거나 훼손된 비상 운영에서만 진행자 정답표로 자물쇠를 대체 개방한다.

## 플레이테스트 기준

아직 실제 플레이테스트를 실시하지 않은 기획 패키지다. 통합 전 최소 3팀(팀당 3~6명), 총 12명 이상으로 아래 기준을 검증한다.

### 통과 기준

- 3팀 중 2팀 이상이 힌트 0~1개로 완료한다.
- 전 팀이 12~18분 안에 완료하고, 중앙값은 14~16분이다.
- 정답 방향의 무작위 찍기 성공은 없고, 모든 팀이 완성 문장과 방향 홈을 근거로 설명한다.
- 팀마다 최소 3명이 표식 회상, 웹 조작, 조각 배열, 자물쇠 입력 중 하나를 수행한다.
- 4명 이상 팀에서는 A~D 담당 전원이 최소 한 번 자신의 정보를 말한다.
- 성경 지식이 없는 참가자도 `더 나은 본향`을 미리 알지 못한 채 관찰과 문장 논리로 정답을 낸다.
- 마지막 선택 뒤 참가자의 70% 이상이 “화살표가 갈 길이 아니라 선택 기록이었다”는 반전을 자기 말로 설명한다.
- 오답 피드백을 읽은 참가자의 80% 이상이 진행자 개입 없이 다음 시도를 바꾼다.
- 문장 배열 오답은 팀당 평균 2회 이하, 방향 자물쇠 오입력은 팀당 1회 이하다.
- 새로고침 1회 후 회수 조각과 반복 기록이 복구되고, 390px 폭에서 선택지·문장 조각이 겹치지 않는다.
- 실제 자물쇠를 연 뒤 웹에 방향을 재입력하지 않고 봉투의 `BETTER-04`로 완료한다.

### 기록할 관찰값

- 시작·표식 합류·네 조각 회수·자물쇠 개방 시각
- 갈림길별 오답 횟수와 같은 오답 반복 횟수
- 요청한 힌트 단계와 요청 시점
- 말하지 못한 표식 담당자 수
- 문장 배열 시도 횟수와 방향 자물쇠 시도 횟수
- 의미 반전을 이해한 순간의 참가자 표현
- 표식 가독성, 설치 위치 혼잡, 다른 팀 단서 엿보기 여부

### 수정 게이트

- 중앙값이 12분 미만이면 표식 위치를 더 벌리고 기억 공유를 선택 전 필수로 만든다.
- 18분 초과 팀이 하나라도 있으면 가장 많이 막힌 표식 문구를 줄이거나 2회 오답 뒤 힌트 1을 자동 표시한다.
- 두 팀 이상이 방향을 찍어 열면 방향 홈 노출 방식을 더 숨기고 자물쇠를 매 회차 초기화한다.
- 두 팀 이상이 마지막 반전을 설명하지 못하면 D 문구와 웹의 `길/기록` 대조 화면을 다시 쓴다.
- 특정 팀원 한 명이 전 과정을 독점하면 토큰별 확인 버튼과 조각 관리자 역할을 운영 규칙에 추가한다.

## 진행자 정답표

- 올바른 웹 선택: `문을 떠난다 → 기억한다 → 좁은 길 → 아직 보이지 않는 곳을 택한다`
- 올바른 문장: `돌아갈 수 있었지만 / 그 길을 떠나 / 더 나은 본향을 / 사모하였다`
- 방향 자물쇠: `오른쪽 → 위 → 왼쪽 → 위`
- 키워드: `더 나은 본향`
- 완료 코드: `BETTER-04`
- 자물쇠 개방 뒤 처리: 봉투의 코드만 활동 페이지에 입력하며 웹에는 방향을 다시 입력하지 않는다.
