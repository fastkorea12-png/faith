# 01 야외 시설 스테이지 패키지 — 너무 오래 머문 자리

## 1. 스테이지 계약 (Stage Contract)

| 항목 | 확정 내용 |
|---|---|
| 대상 | 대학생, 팀당 3~6명 (총 5팀 동시 진행) |
| 목표 시간 | 15~20분 |
| 현장 장소 | 야외 정원, 산책로, 쉼터 및 중앙 잔디밭 주변 |
| 퍼즐 장르 | 발견된 메모 순서 추리 / 현장 표식 탐색 / 물리 키박스 해제 |
| 핵심 질문 | 편안해 보이는 그늘과 쉼터는 과연 영원히 머물 우리의 집인가? |
| 물리 장치 | 4자리 다이얼 키박스 (`2741`, 상자+자물쇠 일체형) |
| 현장 표식 정답 | 표식 A(그늘 넓은 나무=`2`), 표식 B(오래된 벤치=`7`), 표식 C(큰 바위=`4`), 표식 D(길목 이정표=`1`) $\rightarrow$ `2-7-4-1` — 읽는 순서는 자물쇠 번호 목록이 아니라 발견된 메모(§2)의 문장 순서로만 알 수 있다 |
| 결과 키워드 | `장막` (키워드 카드 01 수령) |
| 완료 코드 | `TENT-01` (활동 페이지 입력) |
| 핵심 의미 | 이동 중 만나는 쉼터와 그늘은 잠시 머무는 '장막(텐트)'일 뿐, 영원히 정착할 진짜 본향이 아님을 깨닫는다. |

> [!IMPORTANT]
> `장막`과 `TENT-01`은 용도가 엄격히 분리되어 있다. `장막`은 최종 05 예배당 메타 퍼즐에 사용할 실물 키워드 카드이며, `TENT-01`은 활동 페이지(`activity.html`)에 입력하는 스테이지 해금 코드다.

## 2. 플레이어 경험 및 서사 개요

참가자들은 00 본관에서 첫 정체성(`나그네`)을 확인하고 야외 정원 지대로 진입한다. 야외 현장은 수목, 벤치, 바위, 이정표 등이 넓게 펼쳐진 공간이다.

### 발견된 메모 순서 추리 메커니즘
야외 현장에 도달한 참가자들은 QR을 스캔하여 `game.html?stage=bag` 화면에 접속한다. 화면에는 표식을 읽는 순서를 알려주는 목록이 아니라, **현장에서 발견된 메모 한 장**이 먼저 제시된다.

> "그늘에 앉아 벤치를 보니, 저곳이 더 편해 보이는구나. 내가 머물 곳은 돌베개를 베고 자는 것처럼 불편한 곳이고 싶지는 않다. 하지만 저 길목이 나를 부른다."

이 메모는 순서를 직접 알려주지 않는다. 참가자는 메모 속에서 네 장소(그늘 → 벤치 → 돌베개 → 길목)가 **언급되는 순서**를 스스로 읽어내야 한다. 화면 하단에는 네 위치에 대한 설명 카드가 순서 표시 없이(뒤섞인 채로) 제공되어, "몇 번째"인지는 오직 메모를 다시 읽어야만 알 수 있다.

참가자들은 메모가 알려준 순서(그늘 → 벤치 → 돌 → 길목)대로 각 지점에 부착된 실물 표식 카드의 숫자를 읽어 `2741`이라는 4자리 숫자를 완성하고, 현장 야외 부스/스탠드에 놓인 실물 키박스(`2741`)를 직접 해제한다. 웹 화면에는 자물쇠 번호(`2741`)를 입력하는 칸이 없다 — 그 번호는 물리 키박스를 여는 데만 쓰인다. 대신 상자를 열어야만 알 수 있는 완료 코드(`TENT-01`)를 웹에 입력해야 하며, 이 검증을 통과해야만 스테이지가 완료된다 — 상자를 실제로 열지 않고는 완료 코드를 알 방법이 없다.

## 3. 팀 분업 구조 & 5팀 동시 운영 사양

넓은 야외 공간에서 5개 팀(A~E조)이 효율적으로 탐색하고 병목을 막기 위해 팀 내 역할을 철저히 분담한다.

| 역할 | 담당 행동 | 반드시 공유할 정보 |
|---|---|---|
| 메모 판독관 | 발견된 메모를 소리 내어 읽고, 장소가 언급되는 순서를 팀에 전달 | 메모 순서(그늘$\rightarrow$벤치$\rightarrow$돌$\rightarrow$길목) |
| 현장 관찰관 A (그늘·벤치 구역) | 그늘, 벤치 구역 탐색 | 표식 A (`2`), 표식 B (`7`) 위치 및 실물 숫자 |
| 현장 관찰관 B (돌·길목 구역) | 돌, 길목 구역 탐색 | 표식 C (`4`), 표식 D (`1`) 위치 및 실물 숫자 |
| 기록 대조 & 키박스 해제관 | 4개 표식 결과를 메모 순서대로 조합해 키박스 조작 | 조합 숫자 `2741` 검증 및 키박스 개방 |

### 5팀 동시 운영 동선 관리 및 독립 키트 사양
- **독립 키박스**: A~E조 전용 4자리 다이얼 키박스 5개가 야외 중앙 스탠드에 팀 라벨(A~E)을 달고 개별 배치되어 있다.
- **표식 카드 5세트 배치**: 야외 표식 카드는 4개 위치(그늘, 벤치, 돌, 길목)마다 팀별 표식 코드(A~E)와 서로 다른 테두리 패턴(실선, 점선, 이중선, 사선, 물결선)으로 5장씩 부착되어 있어 타 팀의 카드를 건드리지 않고 독립 수색이 가능하다.
- **메모 5부 배치**: 발견된 메모도 팀별로 5부를 준비해 진입점 근처에 팀 라벨과 함께 흩어 둔다(모두 같은 문구).
- **출발 탐색 순서 분산**: 5팀 동시 시작 시 한 장소로 쏠리는 현상을 방지하기 위해 A/B조는 그늘$\rightarrow$벤치, C/D조는 돌$\rightarrow$길목, E조는 벤치$\rightarrow$돌 방향으로 순환 탐색하도록 안내한다 (단, 최종 조합 순서는 반드시 메모가 알려주는 순서인 그늘$\rightarrow$벤치$\rightarrow$돌$\rightarrow$길목으로 고정됨).

## 4. 현장 단서 및 퍼즐 메카니즘 상세

### 4.1 제공 단서 세트

1. **발견된 메모 (실물, 팀별 5부)**:
   > "그늘에 앉아 벤치를 보니, 저곳이 더 편해 보이는구나. 내가 머물 곳은 돌베개를 베고 자는 것처럼 불편한 곳이고 싶지는 않다. 하지만 저 길목이 나를 부른다."
   - 장소가 언급되는 순서(그늘 → 벤치 → 돌 → 길목)가 곧 표식을 읽는 순서다. 목록이나 번호로 안내하지 않는다.

2. **웹 화면 안내 카드 (`game.html?stage=bag`)**:
   - 4개 위치 설명 카드가 순서 표시 없이(뒤섞인 순서로) 제공된다: 그늘("가장 편한 곳부터 확인"), 길목("다시 길이 갈라지는 자리"), 벤치("둘이 앉지만 한 방향을 보는 자리"), 돌("무게가 놓인 낮은 자리").
   - 각 카드는 그 장소를 현장에서 찾는 법만 알려주고, 몇 번째로 읽어야 하는지는 알려주지 않는다.

3. **4개 현장 표식 실물 카드**: 그늘(느티나무 아래)=`2`, 벤치(오래된 목재 벤치)=`7`, 돌(큰 바위)=`4`, 길목(이정표 기둥 아래)=`1`. 눈높이~지상 1m 이내에 코팅 처리되어 부착.
   - 표식 하단 문구: `"이 그늘과 쉼터는 지친 나그네를 위한 잠시 동안의 장막이다."`

### 4.2 자물쇠 번호 조합 공식
$$\text{자물쇠 암호} = \text{표식 A } (2) \parallel \text{표식 B } (7) \parallel \text{표식 C } (4) \parallel \text{표식 D } (1) = \mathbf{2741}$$

## 7. QR 배치 및 현장 동선

- **QR 위치**: 야외 정원 입구 안내판 및 중앙 쉼터 기둥
- **QR 접속 URL**: `game.html?stage=bag`
- **동선 이동**:
  1. 야외 정원 진입 후 QR 스캔, 발견된 메모 확인.
  2. 메모에 등장하는 순서(그늘 → 벤치 → 돌 → 길목)를 스스로 읽어내고 4개 표식 지점 탐색.
  3. 표식 A(`2`), B(`7`), C(`4`), D(`1`)를 메모 순서대로 읽어 `2741` 조합.
  4. 야외 중앙 스탠드의 키박스(`2741`) 개방, 상자 안 완료 코드 카드(`TENT-01`) 확인.
  5. 웹 화면의 입력창에 `TENT-01`을 입력해 검증 통과(성공 연출 및 `unlock()`).
  6. 활동 페이지(`activity.html`)에 `TENT-01` 입력 후, 미완수된 01~04 스테이지(01 야외, 02 숙소, 03 창고 및 물자 보관소, 04 길 중 남은 장소)로 비선형 자유 이동 (4개 스테이지 완수 후 05 예배당 최종 결집).

## 8. 자물쇠 및 완료 코드 처리 (Lock & Code Handling)

- **물리 자물쇠**: 4자리 다이얼 키박스 `2741` (상자+자물쇠 일체형, 봉투 불필요).
- **상자 내부물**: 완료 코드 카드 1장(`TENT-01`만 인쇄, 숫자 `2741`은 인쇄하지 않는다).
- **올바른 진행 절차**:
  1. 메모가 알려주는 순서대로 현장 표식 4개를 읽어 `2741` 판독.
  2. 키박스 다이얼에 `2741`을 맞춰 직접 연다. 자물쇠 번호는 웹에 입력하지 않는다(설계 원칙 2.5).
  3. 상자 안에서 완료 코드 카드(`TENT-01`)를 꺼내 웹의 입력창에 입력한다.
  4. 정확히 일치해야 `unlock()`이 호출되고 성공 연출과 함께 완료 코드가 화면에 표시된다 — 상자를 실제로 열어 코드를 확인하지 않으면 통과할 수 없다.
  5. 활동 페이지(`activity.html`)에 완료 코드 `TENT-01`을 입력하여 01 스테이지 해금.

## 9. 웹 화면 구현 사양 및 상태 전이

### 웹 화면 역할
웹 화면(`game.html?stage=bag`)은 퍼즐 제출 창이 아니라 **발견된 메모를 보여주는 지침 렌즈**로 작동한다.

- `S0_MEMO`: 발견된 메모 전문과 완료 코드 입력창을 표시. 위치 설명 카드나 순서 목록, 숫자 입력칸은 없다 — 메모가 유일한 단서다.
- `S1_SOLVED`: 입력한 값이 `TENT-01`과 일치하면 `unlock()` 호출, 성공 연출과 함께 완료 코드 표시.
- `S2_COMPLETE`: 완료 코드 확인 및 활동 페이지 이동 안내.

> 웹은 자물쇠 번호(`2741`)를 절대 묻지 않는다 — 그 번호는 실제 키박스를 여는 데만 쓰인다. 대신 상자를 열어야만 알 수 있는 완료 코드(`TENT-01`)를 입력받아, 팀이 실제로 상자를 열었는지를 검증한다. 버튼 하나로 미션이 완수되지 않도록, 상자 안의 코드를 정확히 알아야만 통과한다.

## 10. 진행자 3단계 힌트 가이드 (3-Tier Hint Guide)

1. **시선 (Tier 1)**: `"발견된 메모를 목록이 아니라 이야기로 다시 천천히 읽어 보세요. 장소가 등장하는 순서를 놓치지 않았나요?"`
2. **대조 (Tier 2)**: `"메모 속 순서는 그늘 → 벤치 → 돌베개 → 길목입니다. 이 순서대로 표식의 숫자를 읽어 대조하세요."`
3. **행동 (Tier 3)**: `"표식 그늘=2, 벤치=7, 돌=4, 길목=1 입니다. 키박스 다이얼에 2741을 맞춰 열고, 안에서 찾은 완료 코드를 화면에 입력하세요."`
