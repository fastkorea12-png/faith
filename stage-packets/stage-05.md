# 05 예배당 스테이지 패키지 — 옮겨진 이름 (예비된 성)

## 1. 스테이지 계약

| 항목 | 확정 내용 |
|---|---|
| 대상 | 대학생, 팀당 3~6명 (총 5팀 동시 진행) |
| 목표 시간 | 18~25분 (150분 세션의 최종 메타 퍼즐 & 클라이맥스) |
| 현장 장소 | 예배당 메인 회중석 및 중앙 단상 주변 |
| 장르 | 최종 메타 퍼즐 / 키워드 카드 실물 조합 / 물리 최종 상자 개방 / 귀향 선언문 완성 |
| 핵심 질문 | 00~04 장소에서 모은 다섯 단어는 우리를 어디로 인도하는가? |
| 물리 장치 | 팀별 4자리 번호 자물쇠 (`1116`)가 달린 실물 최종 상자 5개 + 최종 고백 보드 5개 |
| 물리 자물쇠 암호 | `1116` (히브리서 11:16, 실물 자물쇠 전용, 웹에는 입력하지 않음) |
| 웹 키워드 순서 입력 | `나그네` (00 본관) → `장막` (01 야외) → `약속` (02 숙소) → `청지기` (03 주방) → `더 나은 본향` (04 길) + 팀 이름 |
| 웹 상자 개방 승인 | 5개 키워드 검증 후 `[실제 최종 상자를 열었다]` 버튼 클릭 |
| 완성 귀향 선언문 | `"[팀 이름]은 장막을 집으로 착각했던 나그네였지만, 약속을 붙들고 청지기로 살아, 더 나은 본향을 향해 걷는 사람입니다."` |
| 결과 키워드 | `예비된 성` |
| 완료 코드 | `HOMEWARD-05` (활동 페이지 최종 입력 및 세션 종결) |
| 핵심 의미 | 00~04 스테이지에서 얻은 5개 단어가 우연이 아니라 하나님께서 우리를 위해 예비하신 한 성(더 나은 본향)을 향한 순례 과정이었음을 고백하며, 팀 이름으로 귀향 선언을 완성한다. |

`예비된 성`, `HOMEWARD-05`는 각각 용도가 다르다. `예비된 성`은 최종 완성 키워드이며, `HOMEWARD-05`만 활동 페이지(`activity.html`)에 입력하여 세션을 종결한다.

## 2. 플레이어 경험과 사건 개요

팀은 00~04 스테이지를 모두 완수하고 획득한 5장의 실물 키워드 카드(`나그네`, `장막`, `약속`, `청지기`, `더 나은 본향`)를 지니고 예배당에 진입한다.

1. **실물 키워드 카드 배치 및 물리 자물쇠 개방**:
   - 팀은 예배당에 준비된 자신의 팀 "최종 고백 보드"에 5장의 카드를 여정의 순서(`나그네` → `장막` → `약속` → `청지기` → `더 나은 본향`)대로 손으로 직접 안착시킨다.
   - 카드를 올바르게 배열하면 카드 뒷면 도판과 고백 보드의 OHP 암호 격자가 상호 정렬되어 4자리 암호 `1116`이 나타난다.
   - 암호 `1116`으로 팀의 실물 최종 상자(Final Box)에 달린 4자리 번호 자물쇠를 해제한다. (자물쇠 암호 `1116`은 실물 전용이며, 웹에는 입력하지 않는다.)

2. **웹 키워드 검증 및 디지털 귀향 선언문 완성**:
   - 웹 화면(`game.html?stage=home`)에 접속해 5개 현장의 키워드를 순서대로 직접 입력하고 팀 이름을 작성한 후 `[웹 조합 확인]`을 누른다.
     - 00 본관: `나그네`
     - 01 야외: `장막`
     - 02 숙소: `약속`
     - 03 주방: `청지기`
     - 04 길: `더 나은 본향`
     - 팀 이름: 예) `3조 순례자들`
   - 키워드가 정확하면 웹 화면이 "실물 최종 상자" 안내로 전환된다.
   - 실제 최종 상자를 연 후 웹의 `[실제 최종 상자를 열었다]` 버튼을 클릭하면 귀향 선언문이 완성된다:
     `"[팀 이름]은 장막을 집으로 착각했던 나그네였지만, 약속을 붙들고 청지기로 살아, 더 나은 본향을 향해 걷는 사람입니다."`

3. **세션 최종 종결**:
   - 상자 안에서 실물 완료 코드 카드 `HOMEWARD-05`와 실물 귀향 선언문 서식을 확인한다.
   - 활동 페이지(`activity.html`)에 `HOMEWARD-05`를 입력하여 전체 150분 세션을 성공적으로 종결한다.

## 3. 실물 및 웹 2단계 최종 마무리 구조 (Two-Step Finalization)

현장 물리적 개방감과 웹 진행 기록을 결합한 2단계 구조로 완성된다:

1. **실물 카드 조합 & 물리 자물쇠 (`1116`)**: 참가자가 5장의 키워드 카드를 고백 보드에 배치하여 판독한 `1116` 번호 자물쇠를 손으로 직접 개방한다. (자물쇠 번호는 웹에 입력하지 않음).
2. **웹 키워드 순서 입력 & 개방 승인**: 웹에서 5개 키워드 및 팀 이름을 검증받고 `[실제 최종 상자를 열었다]`를 눌러 귀향 선언문 및 완료 코드 `HOMEWARD-05`를 확인한다.
3. **실물 서명 서식 획득**: 상자 안에서 진짜 "귀향 선언문" 수입지를 꺼내 팀원 전원이 모나미 볼펜으로 서명하고 완주 기념사진을 촬영한다.

## 4. 팀 분업 구조 (5팀 동시 운영)

예배당 단상 전면에 5개 팀의 고백 보드와 최종 상자가 독립 배치된다.

| 역할 | 담당 행동 | 반드시 공유할 정보 |
|---|---|---|
| 카드 회수관 | 00~04 키워드 카드 5장 수집 상태 점검 | 5개 키워드 카드 소지 여부 (`나그네`~`더 나은 본향`) |
| 고백 보드 조립관 | 최종 고백 보드에 5개 카드를 순서대로 배치 | 여정의 순서 (00 본관: 나그네 → 01 야외: 장막 → 02 숙소: 약속 → 03 주방: 청지기 → 04 길: 더 나은 본향) |
| 암호 판독관 | OHP 오버레이 필름 정렬 및 `1116` 판독 | 카드 뒷면과 격자가 생성하는 4자리 숫자 (`1116` - 실물 자물쇠 전용) |
| 자물쇠 해제관 | 실물 최종 상자의 `1116` 자물쇠 개방 | 물리 자물쇠 조작 및 귀향 선언문 서식 회수 |
| 웹 승인 & 서명관 | 웹 5개 키워드/팀 이름 입력 후 개방 승인 및 서명 | 웹 완료 코드 `HOMEWARD-05` 확인 및 최종 활동 페이지 입력 |

## 7. QR 배치 및 현장 구성

- **배치 위치**: 예배당 입구 문 및 단상 중앙
- **부착 형태**: A4 스탠드 패널 및 안내 표지판
- **QR 접속 URL**: `game.html?stage=home` (00~04 완료 후 진입)
- **현장 동선**: 5개 팀의 고백 보드와 상자가 1.5m 간격으로 분리 배치되어 타 팀의 자물쇠 암호를 엿보지 않고 팀 자체 추리 및 해제에 집중할 수 있게 유도.

## 8. 자물쇠 및 정답 처리 (Lock & Answer Handling)

- **물리 자물쇠**: 4자리 번호 자물쇠 `1116` (실물 최종 상자 잠금, 실물 전용이며 웹에는 입력하지 않음).
- **정답 처리 프로세스**:
  1. 00~04 키워드 카드 5장을 최종 고백 보드에 순서대로 배치:
     - `나그네` (00 본관) → `장막` (01 야외) → `약속` (02 숙소) → `청지기` (03 주방) → `더 나은 본향` (04 길)
  2. 카드 뒷면 마킹과 OHP 오버레이 필름이 형성하는 암호 `1116` 판독 후 실물 자물쇠 해제.
  3. 웹 화면(`game.html?stage=home`) 접속:
     - 00~04 5개 키워드(`나그네`, `장막`, `약속`, `청지기`, `더 나은 본향`) 및 팀 이름 입력 후 `[웹 조합 확인]` 클릭.
  4. 웹 화면 전환 ("실물 최종 상자"):
     - 안내문 확인 후 `[실제 최종 상자를 열었다]` 버튼 클릭.
  5. 웹상 귀향 선언문 완성 출력:
     - `"[팀 이름]은 장막을 집으로 착각했던 나그네였지만, 약속을 붙들고 청지기로 살아, 더 나은 본향을 향해 걷는 사람입니다."`
  6. 실물 상자 안의 선언문 서식 서명 및 완료 코드 카드 `HOMEWARD-05` 회수 후, 활동 페이지(`activity.html`)에 `HOMEWARD-05` 입력하여 세션 종결.

## 9. 진행자 3단계 힌트 (3 Hint Tiers)

1. **시선 (Tier 1)**: "00부터 04까지 사건파일을 해결하며 얻은 키워드 카드 5장의 순서를 확인하세요. 본관(나그네) → 야외(장막) → 숙소(약속) → 주방(청지기) → 길(더 나은 본향) 순서입니다."
2. **대조 (Tier 2)**: "키워드 카드를 고백 보드에 순서대로 놓고 OHP 격자가 만드는 4자리 숫자 '1116'으로 실물 상자를 열어 주십시오. (1116은 웹에 입력하지 않으며, 실물 자물쇠 전용입니다.)"
3. **행동 (Tier 3)**: "웹 화면에 5개 키워드와 팀 이름을 입력한 뒤 '웹 조합 확인'을 누르고, 전환된 화면에서 '실제 최종 상자를 열었다' 버튼을 눌러 귀향 선언문과 완료 코드 HOMEWARD-05를 확인하십시오."
