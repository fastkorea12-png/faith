# 05 예배당 스테이지 패키지 — 예비된 성 (옮겨진 이름)

## 1. 스테이지 계약 (Stage Contract)

| 항목 | 확정 내용 |
|---|---|
| 대상 | 대학생, 팀당 3~6명 (총 5팀 동시 진행) |
| 목표 시간 | 18~25분 (150분 전체 세션의 클라이맥스 & 메타 퍼즐) |
| 현장 장소 | 예배당 메인 회중석 및 중앙 단상 전면 |
| 퍼즐 장르 | 최종 메타 퍼즐 / 5개 키워드 카드 실물 오버레이 결합 / 귀향 선언문 완성 |
| 핵심 질문 | 00~04 장소에서 모은 다섯 단어는 우리를 어디로 인도하는가? |
| 물리 장치 | 팀별 4자리 자물쇠 (`1116`)가 달린 실물 최종 상자 (Final Box) 5개 |
| 물리 자물쇠 암호 | `1116` (히브리서 11:16 → 장 11 + 절 16. **웹은 이 번호를 절대 표시하지 않는다** — 예배당 말씀판에서 팀이 직접 읽어낸다) |
| 웹 키워드 조합 순서 | `나그네` (00) $\rightarrow$ `장막` (01) $\rightarrow$ `약속` (02) $\rightarrow$ `청지기` (03) $\rightarrow$ `더 나은 본향` (04) + 팀 이름 |
| 완성 귀향 선언문 | `"[팀 이름]은 장막을 집으로 착각했던 나그네였지만, 약속을 붙들고 청지기로 살아, 더 나은 본향을 향해 걷는 사람입니다."` |
| 결과 키워드 | `예비된 성` |
| 완료 코드 | `HOMEWARD-05` (활동 페이지 최종 입력 및 세션 종결) |
| 핵심 의미 | 00~04 스테이지에서 모은 5개 단어가 하나님께서 우리를 위해 예비하신 한 성(더 나은 본향)을 향한 순례의 여정이었음을 고백하고 실물 귀향 선언문에 서명한다. |

> [!IMPORTANT]
> 자물쇠 번호 `1116`은 실물 최종 상자 해제에만 쓰고 웹에 입력하지 않는다. **웹은 이 번호를 알려주지도 않는다** — 팀은 완성한 선언문이 온 구절을 예배당 말씀판에서 찾아 장·절을 이어 붙여 스스로 얻는다. 웹에는 선언문을 조립하고 팀 이름을 넣은 뒤, 상자 안에서 찾은 `HOMEWARD-05`를 입력한다.

> [!NOTE]
> **구조 변경 — 실물 키워드 카드 폐지, 말씀판 도입(2026-08-16)**: 실물 키워드 카드 5장을 나눠주지 않기로 하면서, 카드를 고백 보드에 놓고 OHP 필름을 겹쳐 `1116`을 읽던 원래 장치가 성립하지 않게 됐다(고백 보드·OHP 필름도 함께 폐지). 동시에 기존 웹 구현에는 심각한 누출이 있었다 — ① 다섯 입력칸의 placeholder가 `예: 나그네`처럼 **정답을 그대로 인쇄**했고, ② 선언문 전문이 화면에 표시돼 다섯 키워드가 순서대로 다 보였으며, ③ 물리 단계 안내가 `자물쇠(1116)`라고 **번호를 직접 알려줬다**. 그 결과 키워드를 하나도 회수하지 않은 상태에서도 화면만 베껴 통과됐다(재현 확인).
>
> 이제 웹은 **빈칸 다섯 개짜리 선언문**만 보여주고, 팀이 회수한 낱말 칩을 탭해서 끼워 넣어야 한다(정답 미표시, 여정 순서로 밀어 넣으면 오답). 자물쇠 번호는 웹 어디에도 없고, **예배당 말씀판**(히브리서 11장 구절 다섯 개를 장·절과 함께 게시)에서 선언문이 온 구절을 찾아 장·절을 이어 붙여 얻는다. `11:14`(본향 찾는 자)가 근접 오답으로 함께 실려 있어 문장을 정확히 읽어야 `11:16`(더 나은 본향)에 도달한다. 00~04 미완료 시 05가 잠기는 게이트는 기존대로 유지된다.

## 2. 플레이어 경험 및 서사 개요

팀은 00~04 스테이지를 완수하고 획득한 5장의 실물 키워드 카드(`나그네`, `장막`, `약속`, `청지기`, `더 나은 본향`)를 지니고 클라이맥스 장소인 예배당에 진입한다.

### 실물 카드 배치 및 2단계 최종 종결 구조
1. **실물 카드 수기 배치**:
   - 팀은 웹 선언문 화면에서 회수한 다섯 낱말을 빈칸에 끼워 넣어 문장을 완성한다(탭-투-플레이스). 빈칸 순서(`장막 → 나그네 → 약속 → 청지기 → 더 나은 본향`)는 여정 순서와 다르므로, 얻은 차례대로 밀어 넣으면 맞지 않는다.
   - 완성된 선언문을 들고 **예배당 말씀판**에서 그 문장이 온 구절을 찾는다. 선언문이 향하는 곳(`더 나은 본향`)이 적힌 구절은 히브리서 11장 16절 하나뿐이며, 장·절을 이어 붙이면 `1116`이 된다.
2. **실물 최종 상자 개방**:
   - 스스로 읽어낸 `1116` 번호로 단상에 배치된 실물 최종 상자(Final Box)의 4자리 번호 자물쇠를 연다.
   - 상자 내부에서 `실물 귀향 선언문 서식`, `고급 서명 펜`, `HOMEWARD-05 완료 코드 카드`를 꺼낸다.
3. **웹 선언문 완성 및 실물 서명**:
   - 웹 화면(`game.html?stage=home`)에 5개 키워드와 팀 이름을 입력하여 디지털 귀향 선언문을 확인한다.
   - 팀원 전원이 실물 귀향 선언문 서식에 직접 만년필/볼펜으로 서명하고 완주 기념 촬영을 진행한 뒤, 활동 페이지(`activity.html`)에 `HOMEWARD-05`를 입력하여 전체 150분 방탈출 프로젝트를 종결한다.

## 3. 팀 분업 구조 & 5팀 동시 운영 사양

예배당 단상 전면에 5개 팀(A~E조)의 최종 상자가 1.5m 간격으로 분리 배치되어 독립적인 마무리를 진행한다.

| 역할 | 담당 행동 | 반드시 공유할 정보 |
|---|---|---|
| 선언문 조립관 | 웹 선언문 화면에서 다섯 낱말을 빈칸에 배치 | 문장 순서 `장막 → 나그네 → 약속 → 청지기 → 더 나은 본향` |
| 카드 배치관 | 5개 카드를 여정 순서대로 나란히 배치 | 여정 순서 (나그네 $\rightarrow$ 장막 $\rightarrow$ 약속 $\rightarrow$ 청지기 $\rightarrow$ 더 나은 본향) |
| 말씀판 판독 & 자물쇠 해제관 | 예배당 말씀판에서 선언문이 온 구절을 찾아 장·절을 이어 붙이고, 실물 최종 상자 개방 | 히브리서 11장 16절 → `1116`, 상자 안 선언문 서식 / 서명 펜 / 완료 코드 회수 |
| 웹 승인 & 최종 서명관 | 웹 5개 키워드/팀 이름 입력, 귀향 선언문 낭독 및 팀원 전체 실물 서명 | `HOMEWARD-05` 확인 및 활동 페이지 최종 입력 |

### 5팀 동시 운영 독립 상자 사양
- **독립 최종 상자**: A~E조 전용 실물 최종 우드 상자 5개가 단상 앞에 팀 라벨(A~E)을 붙이고 배치된다.
- **자물쇠 암호 동일성**: 5팀 모두 히브리서 11:16을 뜻하는 `1116` 자물쇠를 사용하되, 각 상자 안에는 해당 팀 라벨이 인쇄된 귀향 선언문 서식이 들어 있어 서로 상자가 바뀌지 않도록 통제한다.

## 4. 현장 단서 및 퍼즐 메카니즘 상세

### 4.1 제공 단서 세트

1. **00~04 회수 키워드 5개** (웹 사건 수첩에 디지털로 자동 수집. 실물 카드는 제작·배포하지 않는다):
   - 00: `나그네` | 01: `장막` | 02: `약속` | 03: `청지기` | 04: `더 나은 본향`

2. **실물 귀향 선언문 서식 (A4 220g 고급 켄트지)**:
   - 귀향 선언문 전문 인쇄 + 하단 팀원 서명 란 (1~6번).

### 4.2 자물쇠 번호 `1116` 및 성경적 근거
- **자물쇠 번호**: **1116** (히브리서 11장 16절: *"그들이 이제는 더 나은 본향을 사모하니 곧 하늘에 있는 것이라 이러므로 하나님이 그들의 하나님이라 일컬음 받으심을 부끄러워하지 아니하시고 그들을 위하여 한 성을 예비하셨느니라"*)

## 7. QR 배치 및 현장 동선

- **QR 위치**: 예배당 입구 문 및 단상 중앙 패널
- **QR 접속 URL**: `game.html?stage=home`
- **동선 이동**:
  1. 예배당 진입 후 QR 스캔(00~04를 모두 완료하지 않았다면 화면이 잠겨 열리지 않는다).
  2. 웹 선언문 화면에서 회수한 다섯 낱말을 빈칸에 끼워 넣어 문장 완성 + 팀 이름 입력.
  3. 예배당 말씀판에서 선언문이 온 구절을 찾아 장·절을 이어 붙여 `1116` 산출.
  4. 단상 전면 실물 최종 상자의 `1116` 자물쇠 개방.
  5. 상자 안에서 선언문 서식, 키워드 카드 05(`예비된 성`), 고급 펜 회수.
  6. 웹 화면에서 5개 키워드와 팀 이름 입력 후 디지털 귀향 선언문 확인.
  7. 실물 선언문 서식에 팀원 전원 서명 후 활동 페이지(`activity.html`)에 `HOMEWARD-05` 입력해 전체 세션 완료.

## 8. 자물쇠 및 완료 코드 처리 (Lock & Code Handling)

- **물리 자물쇠**: 4자리 번호 자물쇠 `1116` (실물 최종 상자 해제용, 웹 입력 없음).
- **올바른 진행 절차**:
  1. 웹에서 선언문을 완성한 뒤, 말씀판에서 그 문장이 온 구절(히브리서 11:16)을 찾아 `1116`을 산출.
  2. 실물 최종 상자의 자물쇠 `1116`을 연 후 서명 서식과 완료 코드를 회수.
  3. 웹 화면(`game.html?stage=home`)에서 5개 키워드(`나그네`, `장막`, `약속`, `청지기`, `더 나은 본향`)와 팀 이름을 입력하여 완료 코드 `HOMEWARD-05`를 확인.
  4. 활동 페이지(`activity.html`)에 `HOMEWARD-05` 입력하여 전체 세션 공식 완료 처리.

## 9. 웹 화면 구현 사양 및 상태 전이

### 웹 상태 전이 (State Transitions)
1. `S0_ARRIVE`: 예배당 도착 환영 및 5개 키워드 수집 확인 안내.
2. `S1_INPUT_KEYWORDS`: 00~04 5개 키워드 입력 필드 + 팀 이름 입력 필드 제공.
3. `S2_VERIFY`: 키워드 조합 검증 및 "실물 최종 상자를 연 후 승인 버튼을 누르라"는 지침.
4. `S3_DECLARATION`: 최종 상자를 열고 안의 종결 카드에 적힌 완료 코드(`HOMEWARD-05`)를 웹에 입력해야 통과된다. 자기신고 버튼은 없으며, 화면에 코드를 미리 노출하지 않는다.
5. `S4_COMPLETE`: 완료 코드 `HOMEWARD-05` 출력 및 활동 페이지 최종 이동 버튼 제공.

### 오답 피드백 문구
- 키워드 순서/오타 오류: `"키워드가 올바르지 않습니다. 00부터 04까지의 결과 키워드를 여정의 순서대로 입력했는지 확인하세요."`

## 10. 진행자 3단계 힌트 가이드 (3-Tier Hint Guide)

1. **시선 (Tier 1)**: `"회수한 다섯 낱말을 선언문의 빈칸에 하나씩 놓아 보세요. 얻은 순서가 아니라, 문장이 자연스럽게 읽히는 순서입니다."`
2. **대조 (Tier 2)**: `"5개 키워드를 웹에 순서대로 입력하면 최종 상자의 자물쇠 번호가 안내됩니다. (그 번호는 웹에 다시 입력하지 말고 실물 자물쇠를 여세요.)"`

## 12. 진행자 정답표 & 운영 해설 (Facilitator Answer Key)

| 검수 항목 | 정답 및 상세 내용 |
|---|---|
| 5개 키워드 여정 순서 | `나그네` (00) $\rightarrow$ `장막` (01) $\rightarrow$ `약속` (02) $\rightarrow$ `청지기` (03) $\rightarrow$ `더 나은 본향` (04) |

### 운영 해설
