# 05 예배당 스테이지 패키지 — 옮겨진 이름 (예비된 성)

## 1. 스테이지 계약

| 항목 | 확정 내용 |
|---|---|
| 대상 | 대학생, 팀당 3~6명 (총 5팀 동시 진행) |
| 목표 시간 | 18~25분 (150분 세션의 최종 메타 퍼즐 & 클라이맥스) |
| 현장 장소 | 예배당 메인 회중석 및 중앙 단상 주변 |
| 장르 | 최종 메타 퍼즐 / 키워드 카드 실물 조합 / 물리 최종 상자 개방 / 귀향 선언문 완성 |
| 핵심 질문 | 00~04 장소에서 모은 다섯 단어는 우리를 어디로 인도하는가? |
| 물리 장치 | 팀별 4자리 번호 자물쇠 (`1116`)가 달린 실물 최종 상자 5개 + 최종 고백 보드 5개 |
| 물리 자물쇠 암호 | `1116` (히브리서 11:16) |
| 웹 키워드 입력 | `나그네` (00) → `장막` (01) → `약속` (02) → `청지기` (03) → `더 나은 본향` (04) |
| 결과 키워드 | `예비된 성` |
| 완료 코드 | `HOMEWARD-05` (활동 페이지 최종 입력 및 세션 종결) |
| 핵심 의미 | 00~04 스테이지에서 얻은 5개 단어가 우연이 아니라 하나님께서 우리를 위해 예비하신 한 성(더 나은 본향)을 향한 순례 과정이었음을 고백하며, 팀 이름으로 귀향 선언을 완성한다. |

`예비된 성`, `HOMEWARD-05`는 각각 용도가 다르다. `예비된 성`은 최종 완성 키워드이며, `HOMEWARD-05`만 활동 페이지(`activity.html`)에 입력하여 세션을 종결한다.

---

## 2. 플레이어 경험과 사건 개요

팀은 00~04 스테이지를 모두 완수하고 획득한 5장의 실물 키워드 카드(`나그네`, `장막`, `약속`, `청지기`, `더 나은 본향`)를 지니고 예배당에 진입한다.

1. 팀은 예배당에 준비된 자신의 팀 "최종 고백 보드"에 5장의 카드를 여정의 순서대로 손으로 직접 안착시킨다.
2. 카드를 올바르게 배열하면 카드 뒷면 도판과 고백 보드의 투명 OHP 암호 격자가 상호 정렬되어 4자리 암호 `1116`이 시각적으로 나타난다.
3. 암호 `1116`으로 팀의 실물 최종 상자(Final Box)에 달린 4자리 번호 자물쇠를 해제한다.
4. 상자 내부에서 고급 켄트지에 인쇄된 "실물 귀향 선언문 서식"과 완료 코드 카드 `HOMEWARD-05`를 획득한다.
5. 웹 화면(`game.html?stage=home`)에서도 5개 키워드를 순서대로 확인하고 팀 이름을 입력하여 디지털 귀향 선언문을 완성한 뒤, 활동 페이지(`activity.html`)에 `HOMEWARD-05`를 입력하여 전체 150분 세션을 성공적으로 종결한다.

---

## 3. 실물 최종 단계 (Real Physical Finalization Step)

기존 기획 및 웹 구현의 "키워드 자동 입력 및 버튼 클릭 마무리" 밋밋함을 완벽하게 극복하는 **현장 실물 클라이맥스 연출**을 적용한다:

1. **실물 카드 조합 필수화**: 참가자가 손으로 직접 5장의 키워드 카드를 고백 보드에 배치하지 않으면 물리 자물쇠 암호를 알 수 없다.
2. **물리 자물쇠 개방 손맛**: `1116` 번호 자물쇠를 직접 손으로 맞추고 찰칵 열리는 물리적 개방감을 제공한다.
3. **실물 서명 서식 획득**: 상자 안에서 진짜 "귀향 선언문" 수입지를 꺼내 팀원 전원이 모나미 볼펜으로 서명하고 완주 기념사진을 촬영한다.

## 4. 팀 분업 구조 (5팀 동시 운영)

예배당 단상 전면에 5개 팀의 고백 보드와 최종 상자가 독립 배치된다.

| 역할 | 담당 행동 | 반드시 공유할 정보 |
|---|---|---|
| 카드 회수관 | 00~04 키워드 카드 5장 수집 상태 점검 | 5개 키워드 카드 소지 여부 (`나그네`~`더 나은 본향`) |
| 고백 보드 조립관 | 최종 고백 보드에 5개 카드를 순서대로 배치 | 여정의 순서 (00 본관 → 01 야외 → 02 숙소 → 03 주방 → 04 길) |
| 암호 판독관 | OHP 오버레이 필름 정렬 및 `1116` 판독 | 카드 뒷면과 격자가 생성하는 4자리 숫자 |
| 자물쇠 해제관 | 실물 최종 상자의 `1116` 자물쇠 개방 | 물리 자물쇠 조작 및 귀향 선언문 서식 회수 |
| 선언문 서명관 | 서식 팀원 서명 및 웹 `HOMEWARD-05` 입력 | 팀 이름 작성 및 최종 활동 페이지 종결 |

## 7. QR 배치 및 현장 구성

- **배치 위치**: 예배당 입구 문 및 단상 중앙
- **부착 형태**: A4 스탠드 패널 및 안내 표지판
- **QR 접속 URL**: `game.html?stage=home` (00~04 완료 후 진입)
- **현장 동선**: 5개 팀의 고백 보드와 상자가 1.5m 간격으로 분리 배치되어 타 팀의 자물쇠 암호를 엿보지 않고 팀 자체 추리 및 해제에 집중할 수 있게 유도.

## 8. 자물쇠 및 정답 처리 (Lock & Answer Handling)

- **물리 자물쇠**: 4자리 번호 자물쇠 `1116` (실물 최종 상자 잠금).
- **정답 처리 프로세스**:
  1. 00~04 키워드 카드 5장을 최종 고백 보드에 순서대로 배치:
     - `나그네` (00) → `장막` (01) → `약속` (02) → `청지기` (03) → `더 나은 본향` (04)
  2. 카드 뒷면 마킹과 OHP 오버레이 필름이 형성하는 암호 `1116` 판독.
  3. 실물 자물쇠 `1116`을 손으로 해제하여 최종 상자 개방.
  4. 상자 안의 실물 귀향 선언문과 `HOMEWARD-05` 완료 코드 카드 수령.
  5. 웹 화면(`game.html?stage=home`)에서 5개 키워드 확인 및 팀 이름 입력 후 디지털 귀향 선언문 확인.
  6. 활동 페이지(`activity.html`)에 `HOMEWARD-05` 입력하여 전체 프로그램 성공 마감.

## 9. 진행자 3단계 힌트 (3 Hint Tiers)

1. **시선 (Tier 1)**: "00부터 04까지 사건파일을 해결하며 얻은 키워드 카드 5장의 순서를 확인하세요. 여정의 출발점(본관)부터 마감점(길)까지의 순서가 고백의 순서입니다."
2. **대조 (Tier 2)**: "키워드 카드를 고백 보드의 빈칸에 '나그네-장막-약속-청지기-더 나은 본향' 순으로 배치하고, 카드 뒷면과 오버레이 격자가 만드는 숫자를 읽으세요."
3. **행동 (Tier 3)**: "히브리서 11장 16절의 의미를 담은 4자리 암호는 '1116'입니다. 상자의 자물쇠에 1116을 입력해 상자를 열고 귀향 선언문을 꺼내십시오."
