# 03 창고 및 물자 보관소 스테이지 패키지 — 맡겨진 것을 바꾼 사람

## 1. 스테이지 계약 (Stage Contract)

| 항목 | 확정 내용 |
|---|---|
| 대상 | 대학생, 팀당 4~6명 (총 5팀 동시 진행, 비선형 자유 순서 순환) |
| 목표 시간 | 12~18분 (표준 15분) |
| 현장 장소 | 창고 및 물자 보관소 (청지기실) 및 인접 물자 보관 공간 |
| 퍼즐 장르 | 3중 대조 감식 (현장 재고 위치 복원 + 웹 변경 기록 + 담당 권한표) |
| 핵심 질문 | 누가 거룩한 보관소의 맡겨진 물물과 질서를 자기 뜻대로 바꾸었는가? |
| 물리 장치 | 3자리 번호 자물쇠 (`432`) — 물자 보관 상자/봉투 03. 공모자 두 명의 확인 코드는 실물 ‘담당별 권한표’에만 인쇄되어 있고 웹에는 후보로 나열되지 않는다 |
| 웹 게임 정답 | 변경 기록 6건에서 “봉인 뒤 물자 이동 + 장부 수정”이 함께 일어났음을 확인 → 권한표상 혼자 둘 다 할 수 있는 사람이 없음을 파악 → 옮긴 사람 `58`(배급 담당)과 적은 사람 `37`(장부 담당)의 코드를 각 칸에 입력 → 인계 표식 순서 공개 (`□` → `△` → `○`) |
| 자물쇠 암호 | `432` (소금 → 기름 → 밀의 복원 선반 번호, 물리 자물쇠 전용) |
| 결과 키워드 | `청지기` (키워드 카드 03 수령) |
| 완료 코드 | `STEWARD-03` (활동 페이지 입력) |
| 핵심 의미 | 청지기는 공동체에 맡겨진 거룩한 물자와 원칙을 자기 편의대로 바꾸는 자가 아니라, 주인의 거룩한 의도와 질서대로 지키고 봉사하는 자임을 깨닫는다. |

> [!IMPORTANT]
> `432`, `청지기`, `STEWARD-03`은 각기 다른 용도다. `432`는 실물 자물쇠를 해제하는 번호(웹에 입력하지 않음), `청지기`는 최종 05 예배당에서 사용할 실물 키워드 카드, `STEWARD-03`은 **상자 안 결과 카드에만 인쇄되어 있으며 웹 화면과 활동 페이지 양쪽에 입력**하는 완료 코드다 — 상자를 실제로 열지 않으면 이 코드를 알 수 없다.

> [!NOTE]
> **장소 변경**: 식당(조리대)을 앞으로 계속 사용할 수 없어, 원래 "조리대 구역"에 두기로 했던 밀·소금 카드 2장은 **보관소 입구 구역**으로 옮겼다. 정답 체계(원래 선반 배치, 조작 3건, 범인, 자물쇠 번호 `432`)는 전혀 바뀌지 않았고, 발견 위치만 바뀐 것이다.

> [!NOTE]
> **구조 변경(찍기 방지)**: 원래는 웹 화면에 담당별 권한표(누가 무엇을 바꿀 권한이 없는지)가 그대로 떠 있었고, 범인도 버튼 4개 중 하나를 클릭해 지목하는 방식이었다. 권한표가 웹에 이미 다 있으니 실물 인쇄물을 안 봐도 됐고, 버튼도 최악 4번이면 찍혀서 통과됐다. 이제 **권한표는 실물 인쇄물에만 있고 웹에는 없다.** 범인 지목도 버튼 클릭이 아니라, 실물 권한표에 역할마다 인쇄된 **확인 코드**를 찾아 입력하는 방식으로 바뀌었다. 코드는 웹 화면 어디에도 후보로 나열되지 않으므로, 실물 인쇄물을 보지 않고는 무엇을 입력해야 할지 알 수 없다.

> [!NOTE]
> **구조 변경 2 — 역할 배정 및 수색 단계 재설계(2026-08-16)**: 원래 1단계는 6개 역할 버튼을 클릭하는 화면이었는데, 클릭해도 게임 로직에 아무 영향이 없는 장식 UI였다(역할을 하나도 안 골라도 다음 단계로 그냥 넘어감). 2단계(수색)는 카드마다 "발견 장소: 보관소 입구" 같은 문구를 웹이 미리 알려줘서, 현장에서 찾기도 전에 스포일러가 됐다. 두 단계를 하나로 합쳐 **서사가 있는 지시문 + 실물 증거 코드 입력**으로 바꿨다: 웹은 "청지기실 긴급 지시서"라는 사건 브리핑 텍스트만 보여주고 역할·발견 위치는 알려주지 않는다. 팀은 현장에서 재고 카드 6장을 실제로 찾아야 하고, 각 카드에 인쇄된 숫자 하나를 표식 순서(○ △ □ ◇ ☆ +)대로 이어 붙인 **6자리 조합 코드**를 웹에 입력해야만 다음 단계(선반 복원)로 넘어간다. 3회 연속 오답 시 10초 잠금(다른 코드 입력 단계와 동일 패턴).

> [!NOTE]
> **구조 변경 3 — 보관 지침 여섯 조건을 인쇄물로 이관(2026-08-16)**: 선반 복원의 추리 재료인 여섯 조건이 웹 화면에만 있어서, 팀이 매트에 카드를 놓으면서 계속 폰을 들여다봐야 했고 추리의 무게중심도 화면 쪽에 있었다. 이제 이 여섯 문장은 **복원 선반 매트 인쇄물의 선반 칸 아래에 직접 인쇄**되고 웹에서는 완전히 제거됐다. 웹은 "매트에 인쇄된 여섯 조건을 읽고 자리를 되돌리라"는 지시서 문장만 보여준다. 팀은 카드·매트·지침을 한 종이 위에서 함께 다루게 되고, 매트 없이는 배치를 추론할 수 없다.

> [!NOTE]
> **구조 변경 4 — 기록 감식을 선택에서 입력으로(2026-08-16)**: 3단계는 여섯 기록 중 세 건을 클릭해 고르는 방식이었다. 경우의 수가 20가지뿐이고 오답 페널티도 없어서, 내용을 전혀 모르는 사람도 눌러보다 보면 통과했다. 페널티를 붙이는 대신 구조를 바꿨다 — 기록은 **읽기 전용 카드**가 되고, 세 조작 기록에만 공통으로 박힌 **변명 문구(`먼저 처리`)를 직접 타이핑**해야 넘어간다. 입력 공간이 무한이라 찍기가 원천 불가능하고, 여섯 기록을 실제로 읽어야만 무엇이 반복되는지 알 수 있다. 3회 연속 오답 시 10초 잠금. 같은 작업에서 기록 카드의 **"기록자: 배급 담당" 표시도 제거**했다 — 이게 남아 있으면 실물 권한표를 보지 않고도 범인을 알 수 있었기 때문이다.

> [!NOTE]
> **구조 변경 5 — 기록 감식과 범인 지목을 하나의 추리로 통합(2026-08-16)**: 구조 변경 4로 클릭 찍기는 막았지만, "세 기록에 반복된 문구를 입력"은 화면에 그대로 세 번 적힌 말을 옮겨 쓰는 수준이라 여전히 추리가 없었다. 게다가 인쇄 권한표는 금지 칸에 `위치·조건 임의 변경 금지 (위반: "먼저 처리" 남발)`이라고 **답을 적어 두어**, 종이는 읽고 판단하는 자료가 아니라 숫자 조회표였다. 두 단계를 하나로 합치고 자료를 갈랐다 — **웹은 "무슨 일이 벌어졌는가"(물자 이동 + 장부 수정이 함께 일어남)만**, **인쇄물은 "누가 무엇을 할 수 있었는가"(이동 가능 여부 / 기재 가능 여부)만** 보여준다. 권한표에서 위반·금지 표현은 전부 걷어냈다. 정답은 둘을 겹쳐야 나오는 결론(둘 다 가능한 사람은 배급 담당뿐)의 확인 코드이며, 웹만으로도 종이만으로도 도달할 수 없다.

> [!NOTE]
> **구조 변경 6 — 2단계 배치 확인 미니게임 추가(2026-08-16)**: 원래 2단계는 "현장 매트 복원 완료" 버튼 하나뿐이라, 팀이 자기 배치가 맞는지 확인할 방법이 전혀 없었다. 틀린 채로 3·4단계를 지나 **마지막 자물쇠에 가서야** 실패를 알게 되고, 그때는 무엇이 틀렸는지도 알 수 없어 되짚기가 어려웠다. 이제 웹에 **배치 확인 미니게임**을 넣었다 — 품목 칩을 눌러 고르고 선반 칸을 눌러 올리는 탭-투-플레이스 방식(390px에서 드래그는 오작동이 잦아 배제)이며, `배치 확인`을 누르면 즉시 맞고 틀림을 알려준다. 추리 재료인 여섯 조건은 여전히 **매트 인쇄물에만** 있고 정답 배치도 화면에 표시하지 않으므로, 미니게임은 답을 알려주는 장치가 아니라 팀이 스스로 세운 답을 검증받는 장치다. 3회 연속 오답 시 10초 잠금.

> [!NOTE]
> **구조 변경 7 — 단독범에서 두 사람의 공모로(2026-08-16)**: 범인이 배급 담당 하나뿐이라 답이 코드 한 개(`58`)로 끝나 밋밋했다. 이제 권한표를 바꿔 **혼자서 두 가지를 다 할 수 있는 사람이 없게** 만들었다 — 봉인 뒤 반출은 배급 담당만, 장부 기재는 장부 담당만 가능하다. 따라서 조작은 서로 권한을 빌려준 **두 사람의 공모**여야만 성립하고, 팀은 옮긴 사람(`58`)과 적은 사람(`37`)을 **각각** 지목해야 한다(역할을 바꿔 넣으면 통과되지 않는다). 오답 피드백은 어느 쪽이 맞고 틀렸는지만 짚어 주고 정답은 주지 않는다. 서사도 이에 맞춰, 둘 다 훔치지 않았고 서로를 도왔다고 여겼지만 그 순간 맡긴 이의 질서가 사라졌다는 결말로 바꿨다.
>
> 같은 작업에서 표시 버그도 고쳤다: 03은 밝은 수첩 지면인데 `.phone-answer-form` 계열이 02의 어두운 폰 화면 전제(흰 글자)라 **입력칸 레이블과 잠금 카운트다운이 보이지 않았다**. `#ledgerFlow` 범위로 대비를 되돌렸다.

## 2. 플레이어 경험 및 서사 개요

본향을 향해 걷는 순례자 공동체를 위해 하나님께서 맡겨주신 거룩한 보물이자 생명의 물자(밀, 기름, 소금, 콩, 건과일, 물)가 보관된 **창고 및 물자 보관소 (청지기실)**에 불의한 장부 조작 사건이 발생한다.

구호 물물 인계 직전, 거룩한 보관소의 6개 품목 중 3개 핵심 품목(소금, 기름, 밀)이 지정된 정결한 선반에서 임의로 치워졌고, 장부 기록 역시 "먼저 처리"라는 가짜 청지기의 임의적 핑계로 고쳐졌다.
참가자들은 00 오프닝 후 비선형 자유 탐색으로 진입하여, 현장에 흩어진 6장의 재고 카드를 회수해 `선반 매트`에 원래 거룩한 질서대로 복원하고, 웹 화면의 `변경 기록 6건`과 인쇄된 `담당별 권한표`를 3중 대조하여 범인(`배급 담당`)을 확정 코드로 지목한다.

### 3중 대조 메커니즘 (Triple Verification)
1. **1차 (현장 재고 카드 ↔ 원본 보관 지침)**: 현장에서 회수한 카드를, 웹이 제시한 여섯 개 보관 조건을 조합해 원래 선반 위치로 복원 (거룩한 물물 배치 복원). 웹은 정답을 알려주지 않으므로 매트를 직접 채워야 한다.
2. **2차 (웹 변경 기록 ↔ 실물 권한표) — 공모 판별**: 웹은 **무슨 일이 벌어졌는지**만 보여준다 — 세 건은 봉인 뒤에 물자가 자리를 떠났고, 거기에 더해 장부 문장까지 고쳐 쓰였다. 실물 권한표는 **누가 무엇을 할 수 있었는지**만 보여준다(봉인 뒤 반출 가능 여부 / 장부 기재 가능 여부). 둘을 겹치면 **혼자서 두 가지를 다 할 수 있는 사람이 없다**는 사실이 드러난다 — 봉인 뒤 반출은 배급 담당만, 장부 기재는 장부 담당만 가능하다. 즉 서로 권한을 빌려준 두 사람의 공모이며, 팀은 **옮긴 사람(`58`)과 적은 사람(`37`)을 각각 지목**해야 한다. 웹에는 담당자 이름도 코드도 없고, 인쇄물에는 누가 범인인지 적혀 있지 않다.
3. **3차 (표식 순서 → 자물쇠 번호)**: 범인 확정 코드가 맞으면 공개되는 표식 순서(`□` → `△` → `○`)대로 복원 선반 번호를 읽어 `432` 완성.

## 3. 팀 분업 구조 & 5팀 동시 운영 사양 (비선형 자유 탐색 및 교차 순환)

00 본관 완료 후, 5개 팀(A~E조)은 01~04 4개 스테이지를 정해진 순서 없이 자유롭게 순환 탐색한다. 5개 팀이 서로 다른 타임라인으로 창고 및 물자 보관소에 입장하거나 동시 교차 수색을 진행하므로, 병목 없이 독립적인 수색 및 대조를 진행할 수 있도록 역할을 분담하고 동선을 통제한다.

아래 역할은 지시서 안에 서사적으로 녹여 제시되는 **권장 분담**이며, 웹이 버튼으로 강제 배정하지 않는다(예전엔 클릭식 역할 배정 화면이 있었지만 실제로 아무 것도 검증하지 않아 제거했다 — [!NOTE] "구조 변경 2" 참고). 팀이 알아서 나눠도 되고, 그대로 따라도 된다.

| 역할 | 담당 행동 | 반드시 공유할 정보 |
|---|---|---|
| 수색 담당 A (보관소 입구 구역) | 입구 주변 카드의 위치 기록 및 회수 | `밀=입구`, `소금=입구` 발견 정보 + 카드에 적힌 숫자 |
| 수색 담당 B (창고 선반/출입구 구역) | 창고 내부 선반 및 출입구 주변 카드의 위치 기록 및 회수 | `기름=출입구`, `콩=선반5`, `건과일=선반1`, `물=선반6` + 카드에 적힌 숫자 |

| 보관 복원 담당 | 매트에 인쇄된 보관 지침 6개 조건을 조합해 실물 매트(1~6)에 카드 6장 복원 후, 같은 배치를 웹 미니게임에 옮겨 담아 확인 | 유일한 배치: `1건과일 / 2밀 / 3기름 / 4소금 / 5콩 / 6물` |

### 5팀 교차 순환 동선 사양 및 독립 키트 사양
- **비선형 자유 탐색 순환 규칙**: 5개 팀은 00 완료 후 01~04 스테이지를 원하는 순서대로 방문한다. 팀별 출발 장소를 분산(예: A팀→01, B팀→02, C팀→03, D팀→04, E팀→자유)시켜 03 창고 및 물자 보관소에 순차적/교차적으로 진입하게 유도한다.
- **독립 재고 카드 세트**: 팀별 6장의 재고 카드는 팀 코드(A~E)와 흑백 테두리 패턴(실선, 점선, 이중선, 사선, 물결선)으로 구분되어 카드가 섞이거나 앞팀이 조사 중이더라도 1초 만에 분리 가능하다.
- **수색 구역 오프셋 배치**: 5팀의 수색 대상 위치는 동일 구역 내 30~50cm 오프셋으로 분산 배치되어 팀 간 동선 충돌 및 엿보기를 철저히 방지한다.

## 4. 현장 단서 및 퍼즐 메카니즘 상세

### 4.1 제공 단서 세트

1. **현장 재고 카드 6장 (팀 표식 포함, 카드마다 조합 숫자 1개 인쇄)**:
   - `밀` (인계 표식: `○`, 발견: 보관소 입구 구역, 카드 숫자: `4`)
   - `기름` (인계 표식: `△`, 발견: 창고 출입구 구역, 카드 숫자: `1`)
   - `소금` (인계 표식: `□`, 발견: 보관소 입구 구역, 카드 숫자: `6`)
   - `콩` (인계 표식: `◇`, 발견: 선반 5, 카드 숫자: `2`)
   - `건과일` (인계 표식: `☆`, 발견: 선반 1, 카드 숫자: `5`)
   - `물` (인계 표식: `+`, 발견: 선반 6, 카드 숫자: `3`)

   웹은 "발견 장소"를 알려주지 않는다 — 전부 현장에서 실제로 찾아야 한다. 6장을 모두 찾으면 표식 순서(○ △ □ ◇ ☆ +)대로 숫자를 이어 붙여 **조합 코드 `416253`**을 완성하고, 웹에 입력해야 다음 단계(선반 복원)로 넘어간다.

2. **인쇄물 — 복원 선반 매트 + 봉인 전 보관 지침** (웹에는 없음, 실물 인쇄물 전용):

   매트 상단에는 선반 1~6 빈 칸이, **그 아래에 여섯 개의 보관 지침 문장**이 함께 인쇄된다. 팀은 매트에 카드를 올리면서 같은 종이에서 조건을 읽는다 — 웹에는 이 여섯 문장이 어디에도 나오지 않으므로, 매트 없이는 배치를 추론할 수 없다(선반 1이 가장 위, 6이 가장 아래).

   1. 밀과 기름과 소금은 매일 함께 배급되므로, 서로 잇닿은 세 칸에 나란히 둔다.
   2. 그 세 칸의 가운데 칸은 기름의 자리다.
   3. 소금은 기름보다 아래 칸에 둔다.
   4. 콩 바로 아래 칸은 물의 자리다.
   5. 건과일은 밀과 맞닿은 칸에 둔다.
   6. 물이 새어도 마른 것이 상하지 않도록, 물은 건과일보다 아래 칸에 둔다.

   여섯 조건을 모두 만족하는 배치는 **`1건과일 / 2밀 / 3기름 / 4소금 / 5콩 / 6물` 하나뿐**이며, 여섯 조건 모두 필요하다(하나라도 빼면 해가 2~6개로 늘어남 — 전수 탐색으로 검증).

   > 웹 화면은 조건 자체를 보여주지 않는다(조건은 매트 인쇄물 전용). 대신 **배치 확인 미니게임**을 제공한다: 팀이 실물 매트에 놓은 배치를 화면의 선반 1~6 칸에 그대로 옮겨 담고 `배치 확인`을 누르면 맞고 틀림을 즉시 알려준다. 정답 배치는 화면에 표시되지 않으며(팀이 올린 칩만 보인다) 판정만 돌려준다. 3회 연속 오답 시 10초 잠금.

3. **인쇄물 — 담당별 권한표** (웹에는 없음, 실물 인쇄물 전용). 누가 위반했는지는 **적혀 있지 않다** — 오직 "누가 무엇을 할 수 있는가"만 적혀 있고, 범인은 웹 증거와 겹쳐야 나온다:
   | 담당 | 물자를 옮길 수 있는가 | 장부를 쓸 수 있는가 | 확인 코드(인쇄) |
   |---|---|---|---|
   | 보관 담당 | 가능 — 단, **봉인 전까지만** | 불가 | `24` |
   | 장부 담당 | 불가 | 가능 — 인계가 끝난 뒤 문장 확정 | `37` |
   | 열쇠 담당 | 불가 — 문만 여닫는다 | 불가 | `45` |
   | 배급 담당 | 가능 — 배급 때 직접 반출 | 가능 — 반출 내역을 직접 기재 | `58` |

   **담당자 진술**(표 아래 함께 인쇄, 표와 같은 내용을 서사로 뒷받침):
   - 보관 담당: "봉인 전에 여섯 자리를 지침대로 채웠다. 봉인 뒤로는 선반에 손대지 않았다."
   - 장부 담당: "나는 인계가 끝난 뒤에만 문장을 확정한다. 물자에는 손대지 않는다."
   - 열쇠 담당: "나는 문을 여닫을 뿐, 물자도 장부도 만지지 않는다."
   - 배급 담당: "급한 물자는 내가 직접 꺼내 나르고, 나른 내역도 내가 적는다."

   4개 역할 모두에 코드를 인쇄해 둔다 — 한 명만 코드가 있으면 "코드 있는 항목이 정답"이라고 눈치챌 수 있기 때문이다. 웹은 코드도 역할 이름도 보여주지 않는다.

4. **웹 화면 B — 변경 기록 6건** (읽기 전용 카드, 고르는 UI 아님):
   - 조작 3건: `밀` (보관소 입구, "먼저 처리 — 보관소 입구로 이동"), `기름` (출입구, "먼저 처리 — 출입구로 이동"), `소금` (보관소 입구, "먼저 처리 — 보관소 입구로 이동")
   - 정상 3건: `콩` (선반5, "확인 뒤 인계 — 원래 자리 유지"), `건과일` (선반1, "확인 뒤 인계"), `물` (선반6, "확인 뒤 인계")
   - **기록자 이름은 웹에 표시하지 않는다.** 예전엔 조작 3건에 "기록자: 배급 담당"이 그대로 찍혀 있어 실물 권한표를 보지 않고도 범인을 알 수 있었다. 이제 누가 썼는지는 실물 권한표를 읽고 판단해야 한다.
   - 이 여섯 기록이 알려주는 것은 **무슨 일이 벌어졌는가**뿐이다: 세 건은 봉인 뒤에 물자가 자리를 떠났고, 거기에 더해 장부 문장까지 고쳐 쓰였다(두 가지가 함께 일어났다). **누가** 했는지는 실물 권한표를 겹쳐야 나온다.
   - 팀이 할 일은 **옮긴 사람과 적은 사람을 각각 지목**해, 권한표에 인쇄된 두 사람의 확인 코드(`58`·`37`)를 두 칸에 나눠 넣는 것이다. 코드 두 개를 찾는 것으로 끝나지 않고, 누가 무엇을 했는지까지 갈라야 통과된다. 3회 연속 오답 시 10초 잠금.
   - 오답 피드백은 어느 칸이 틀렸는지만 알려준다(한쪽만 맞은 경우 그 사실을 짚어 주고, 두 칸에 같은 사람을 넣으면 “혼자서는 할 수 없었다”를 다시 짚어 준다). 정답은 알려주지 않는다.

### 4.2 자물쇠 번호 `432` 산출 과정
1. 범인 지목 성공 시 웹이 인계 표식 순서 공개: `□ → △ → ○`
2. 해당 품목: `소금` (`□`) → `기름` (`△`) → `밀` (`○`)
3. 복원 선반 매트에서 각 품목의 원래 선반 번호 읽기:
   - `소금` (`□`) = **선반 4**
   - `기름` (`△`) = **선반 3**
   - `밀` (`○`) = **선반 2**
4. **물리 자물쇠 암호** = **432**

## 8. 자물쇠 및 완료 코드 처리 (Lock & Code Handling)

- **물리 자물쇠**: 3자리 번호 자물쇠 `432` (물자 보관 상자/봉투 03 해제용).
- **올바른 진행 절차**:
  1. 3중 대조로 복원한 선반 번호 `432`로 물리 자물쇠 상자 03 개방.
  2. 상자 내부에서 키워드 카드 03(`청지기`)과 완료 코드 `STEWARD-03` 회수.
  3. `432`는 물리 자물쇠 전용이므로 웹에 입력하지 않음. 대신 상자 안 결과 카드의 완료 코드 `STEWARD-03`을 웹에 입력해야 스테이지가 통과된다(자기신고 버튼 없음).
  4. 활동 페이지(`activity.html`)에 완료 코드 `STEWARD-03` 입력해 스테이지 해금.

## 9. 웹 화면 구현 사양 및 상태 전이

### 웹 상태 전이 (State Transitions)
1. `S0_BRIEFING`: "청지기실 긴급 지시서" 서사 텍스트 표시. 발견 위치·역할 배정 없음. 6자리 조합 코드 입력 폼 제공, 3회 연속 오답 시 10초 잠금.
2. `S1_RESTORE`: "매트에 인쇄된 여섯 조건을 읽고 자리를 되돌리라"는 지시서 문장 + **배치 확인 미니게임**(선반 1~6 칸에 품목 칩을 탭해서 올리는 방식). 조건 6개와 정답 배치는 웹에 노출하지 않는다. 팀이 옮겨 담은 배치가 정답과 일치해야 다음 단계로 넘어간다. 3회 연속 오답 시 10초 잠금.
3. `S2_AUDIT`: 기록 감식과 공모자 지목을 합친 단일 단계. 변경 기록 6건을 읽기 전용 카드로 제시(기록자 이름·역할명·코드 모두 미표시)하고, **입력칸 두 개**(옮긴 사람 / 적은 사람)로 공모자 코드를 각각 입력받는다. 선택지 없음. 3회 연속 오답 시 10초 잠금.
5. `S4_UNLOCK`: 지목 성공 시 인계 표식 순서 `□ 소금 → △ 기름 → ○ 밀` 공개. **선반 번호는 표시하지 않는다** — 팀이 2단계에서 복원한 매트를 직접 읽어 `432`를 얻어야 한다.
6. `S5_COMPLETE`: 상자 개방 확인 및 활동 페이지 코드 입력 안내.

### 오답 피드백 문구
- 조합 코드 오답 시: `"그 조합은 맞지 않습니다. 여섯 장의 카드를 표식 순서(○ △ □ ◇ ☆ +)대로 다시 확인하십시오."`
- 두 칸에 같은 사람: `"한 사람이 두 가지를 다 할 수는 없었습니다. 권한표를 다시 보고 서로 다른 두 사람을 찾으십시오."`
- 한쪽만 정답(옮긴 사람만 맞음): `"물자를 옮긴 쪽은 맞습니다. 다만 그 사람은 장부에 문장을 쓸 수 없었습니다."`
- 한쪽만 정답(적은 사람만 맞음): `"장부 쪽은 맞습니다. 다만 그 사람은 봉인 뒤에 물자를 옮길 수 없었습니다."`
- 둘 다 오답: `"두 칸 모두 맞지 않습니다. 봉인 뒤에 물자를 꺼낼 수 있었던 사람과, 장부에 문장을 쓸 수 있었던 사람을 각각 찾으십시오."`
- 권한표에 없는 번호: `"권한표에 없는 번호가 있습니다. 네 담당자 옆에 인쇄된 확인 코드를 다시 확인하십시오."` (모두 3회 연속 오답 시 10초 잠금)
- 확인 코드 오답 시: `"그 코드로는 결론이 확정되지 않습니다. 실물 권한표에서 위치·조건을 임의로 바꿀 수 없는 담당자를 다시 찾으십시오."`

## 10. 진행자 3단계 힌트 가이드 (3-Tier Hint Guide)

1. **시선 (Tier 1)**: `"먼저 재고 카드 6장을 현장에서 모두 찾으세요. 카드에 적힌 숫자를 표식 순서(○ △ □ ◇ ☆ +)대로 이어 붙이면 여섯 자리 코드가 됩니다. 카드가 발견된 곳과 원래 있어야 할 곳은 다릅니다 — 선반 매트 아래쪽에 인쇄된 보관 지침 여섯 조건을 조합해 매트(1~6)를 채워 보세요."`
2. **대조 (Tier 2)**: `"매트에 인쇄된 보관 지침은 '밀·기름·소금이 잇닿은 세 칸'에서 출발하세요 — 그 덩어리가 들어갈 자리는 많지 않습니다(가운데가 기름, 소금이 아래). 그리고 변경 기록 세 건을 보면 봉인 뒤에 물자가 자리를 옮겼을 뿐 아니라 장부 문장까지 바뀌어 있습니다. 권한표를 보면 이 둘을 혼자 할 수 있는 사람이 없습니다 — 두 사람이 서로 권한을 빌려준 겁니다."`
3. **행동 (Tier 3)**: `"권한표에서 봉인 뒤 반출이 '가능'인 사람은 배급 담당, 장부 기재가 '가능'인 사람은 장부 담당뿐입니다. 두 사람의 확인 코드를 각 칸에 나눠 넣으면, 표식 순서(네모→세모→동그라미, 즉 소금→기름→밀)가 공개됩니다. 매트의 선반 번호를 읽으세요 (4-3-2). 자물쇠 번호는 432입니다."`
