# 03 창고 및 물자 보관소 스테이지 패키지 — 맡겨진 것을 바꾼 사람

## 1. 스테이지 계약 (Stage Contract)

| 항목 | 확정 내용 |
|---|---|
| 대상 | 대학생, 팀당 4~6명 (총 5팀 동시 진행, 비선형 자유 순서 순환) |
| 목표 시간 | 12~18분 (표준 15분) |
| 현장 장소 | 창고 및 물자 보관소 (청지기실) 및 인접 물자 보관 공간 |
| 퍼즐 장르 | 3중 대조 감식 (현장 재고 위치 복원 + 웹 변경 기록 + 담당 권한표) |
| 핵심 질문 | 누가 거룩한 보관소의 맡겨진 물물과 질서를 자기 뜻대로 바꾸었는가? |
| 물리 장치 | 3자리 번호 자물쇠 (`432`) — 물자 보관 상자/봉투 03 |
| 웹 게임 정답 | 범인 지목 (`배급 담당`) → 인계 표식 순서 공개 (`□` → `△` → `○`) |
| 자물쇠 암호 | `432` (소금 → 기름 → 밀의 복원 선반 번호, 물리 자물쇠 전용) |
| 결과 키워드 | `청지기` (키워드 카드 03 수령) |
| 완료 코드 | `STEWARD-03` (활동 페이지 입력) |
| 핵심 의미 | 청지기는 공동체에 맡겨진 거룩한 물자와 원칙을 자기 편의대로 바꾸는 자가 아니라, 주인의 거룩한 의도와 질서대로 지키고 봉사하는 자임을 깨닫는다. |

> [!IMPORTANT]
> `432`, `청지기`, `STEWARD-03`은 각기 다른 용도다. `432`는 실물 자물쇠를 해제하는 번호(웹에 다시 입력하지 않음), `청지기`는 최종 05 예배당에서 사용할 실물 키워드 카드, `STEWARD-03`만 활동 페이지(`activity.html`)에 입력하는 완료 코드다.

> [!NOTE]
> **장소 변경**: 식당(조리대)을 앞으로 계속 사용할 수 없어, 원래 "조리대 구역"에 두기로 했던 밀·소금 카드 2장은 **보관소 입구 구역**으로 옮겼다. 정답 체계(원래 선반 배치, 조작 3건, 범인, 자물쇠 번호 `432`)는 전혀 바뀌지 않았고, 발견 위치만 바뀐 것이다.

## 2. 플레이어 경험 및 서사 개요

본향을 향해 걷는 순례자 공동체를 위해 하나님께서 맡겨주신 거룩한 보물이자 생명의 물자(밀, 기름, 소금, 콩, 건과일, 물)가 보관된 **창고 및 물자 보관소 (청지기실)**에 불의한 장부 조작 사건이 발생한다.

구호 물물 인계 직전, 거룩한 보관소의 6개 품목 중 3개 핵심 품목(소금, 기름, 밀)이 지정된 정결한 선반에서 임의로 치워졌고, 장부 기록 역시 "먼저 처리"라는 가짜 청지기의 임의적 핑계로 고쳐졌다.
참가자들은 00 오프닝 후 비선형 자유 탐색으로 진입하여, 현장에 흩어진 6장의 재고 카드를 회수해 `선반 매트`에 원래 거룩한 질서대로 복원하고, 웹 화면의 `변경 기록 6건`과 인쇄된 `담당별 권한표`를 3중 대조하여 범인(`배급 담당`)을 지목한다.

### 3중 대조 메커니즘 (Triple Verification)
1. **1차 (현장 재고 카드 ↔ 원본 선반 안내도)**: 현장에서 회수한 카드의 원래 선반 위치를 복원 (거룩한 물물 배치 복원).
2. **2차 (웹 변경 기록 ↔ 권한표)**: 임의로 문장을 고치고 거룩한 질서를 왜곡한 기록자(`배급 담당`) 및 동일 변명 문구(`먼저 처리`) 가려내기.
3. **3차 (표식 순서 → 자물쇠 번호)**: 범인 지목 성공 시 공개되는 표식 순서(`□` → `△` → `○`)대로 복원 선반 번호를 읽어 `432` 완성.

## 3. 팀 분업 구조 & 5팀 동시 운영 사양 (비선형 자유 탐색 및 교차 순환)

00 본관 완료 후, 5개 팀(A~E조)은 01~04 4개 스테이지를 정해진 순서 없이 자유롭게 순환 탐색한다. 5개 팀이 서로 다른 타임라인으로 창고 및 물자 보관소에 입장하거나 동시 교차 수색을 진행하므로, 병목 없이 독립적인 수색 및 대조를 진행할 수 있도록 역할을 분담하고 동선을 통제한다.

| 역할 | 담당 행동 | 반드시 공유할 정보 |
|---|---|---|
| 수색 담당 A (보관소 입구 구역) | 입구 주변 카드의 위치 기록 및 회수 | `밀=입구`, `소금=입구` 발견 정보 |
| 수색 담당 B (창고 선반/출입구 구역) | 창고 내부 선반 및 출입구 주변 카드의 위치 기록 및 회수 | `기름=출입구`, `콩=선반5`, `건과일=선반1`, `물=선반6` |
| 보관 복원 담당 | 웹 원본 안내문만 보고 선반 매트(1~6)에 카드 6장 복원 | 원래 배치: `1건과일 / 2밀 / 3기름 / 4소금 / 5콩 / 6물` |
| 기록 감식 담당 | 웹 변경 기록 6건을 소리 내어 읽고 문구 대조 | 조작 문구 `먼저 처리` 사용 항목 3건 추출 |
| 권한 확인 담당 | 인쇄물 담당별 권한표 확인 | `배급 담당`은 위치/조건 임의 변경 권한 없음 판정 |
| 최종 발표 & 자물쇠 해제관 | 팀 추리 종합, 범인(`배급 담당`) 선택 및 `432` 개방 | `□`(소금:선반4) → `△`(기름:선반3) → `○`(밀:선반2) → `432` |

### 5팀 교차 순환 동선 사양 및 독립 키트 사양
- **비선형 자유 탐색 순환 규칙**: 5개 팀은 00 완료 후 01~04 스테이지를 원하는 순서대로 방문한다. 팀별 출발 장소를 분산(예: A팀→01, B팀→02, C팀→03, D팀→04, E팀→자유)시켜 03 창고 및 물자 보관소에 순차적/교차적으로 진입하게 유도한다.
- **독립 재고 카드 세트**: 팀별 6장의 재고 카드는 팀 코드(A~E)와 흑백 테두리 패턴(실선, 점선, 이중선, 사선, 물결선)으로 구분되어 카드가 섞이거나 앞팀이 조사 중이더라도 1초 만에 분리 가능하다.
- **수색 구역 오프셋 배치**: 5팀의 수색 대상 위치는 동일 구역 내 30~50cm 오프셋으로 분산 배치되어 팀 간 동선 충돌 및 엿보기를 철저히 방지한다.

## 4. 현장 단서 및 퍼즐 메카니즘 상세

### 4.1 제공 단서 세트

1. **현장 재고 카드 6장 (팀 표식 포함)**:
   - `밀` (인계 표식: `○`, 발견: 보관소 입구 구역)
   - `기름` (인계 표식: `△`, 발견: 창고 출입구 구역)
   - `소금` (인계 표식: `□`, 발견: 보관소 입구 구역)
   - `콩` (인계 표식: `◇`, 발견: 선반 5)
   - `건과일` (인계 표식: `☆`, 발견: 선반 1)
   - `물` (인계 표식: `+`, 발견: 선반 6)

2. **웹 화면 A — 원본 선반 안내도 (`game.html?stage=ledger`)**:
   - `건과일` = 가장 위 선반 (선반 1)
   - `밀` = 기름 바로 위 (선반 2)
   - `기름` = 소금 바로 위 (선반 3)
   - `소금` = 콩 바로 위 (선반 4)
   - `콩` = 물 바로 위 (선반 5)
   - `물` = 가장 아래 선반 (선반 6)

3. **인쇄물 — 담당별 권한표**:
   - `보관 담당`: 선반 배치 권한 | 장부 수정 불가
   - `장부 담당`: 인계 문장 확정 권한 | 위치 변경 불가
   - `열쇠 담당`: 입회 창고 개방 권한 | 단독 변경 불가
   - `배급 담당`: 확정 장부 전달 권한 | **위치·조건 임의 변경 금지 (위반: "먼저 처리" 남발)**

4. **웹 화면 B — 변경 기록 6건**:
   - 조작 3건: `밀` (보관소 입구, "먼저 처리", 배급 담당), `기름` (출입구, "먼저 처리", 배급 담당), `소금` (보관소 입구, "먼저 처리", 배급 담당)
   - 정상 3건: `콩` (선반5, "확인 뒤 인계", 장부 담당), `건과일` (선반1, "확인 뒤 인계", 보관 담당), `물` (선반6, "확인 뒤 인계", 열쇠 담당)

### 4.2 자물쇠 번호 `432` 산출 과정
1. 범인 지목 성공 시 웹이 인계 표식 순서 공개: `□ → △ → ○`
2. 해당 품목: `소금` (`□`) → `기름` (`△`) → `밀` (`○`)
3. 복원 선반 매트에서 각 품목의 원래 선반 번호 읽기:
   - `소금` (`□`) = **선반 4**
   - `기름` (`△`) = **선반 3**
   - `밀` (`○`) = **선반 2**
4. **물리 자물쇠 암호** = **432**

## 7. QR 배치 및 현장 동선

- **QR 위치**: 창고 및 물자 보관소 입구 및 중앙 안내판
- **QR 접속 URL**: `game.html?stage=ledger`
- **동선 이동 (비선형 자유 탐색 체계)**:
  1. 00 본관 완료 후 비선형 순환 순서에 따라 창고 및 물자 보관소 진입 후 QR 스캔.
  2. 수색 담당자들이 물자 보관소 곳곳에서 팀 라벨이 붙은 재고 카드 6장 수색.
  3. 보관 복원 담당이 웹 원본 안내문에 맞춰 선반 매트에 카드 6장 복원.
  4. 웹 변경 기록 6건과 권한표 대조하여 조작 기록 3건 및 범인(`배급 담당`) 지목.
  5. 공개된 표식 순서 `□ → △ → ○` 에 따라 선반 번호 `432` 독해.
  6. 실물 상자 03의 자물쇠 `432` 개방 후 키워드 카드 03(`청지기`) 수령 및 활동 페이지(`activity.html`)에 `STEWARD-03` 입력.
  7. 미완수된 남은 스테이지(01~04 중)로 자유 이동 (4개 스테이지 완수 후 05 예배당 최종 결집).

## 8. 자물쇠 및 완료 코드 처리 (Lock & Code Handling)

- **물리 자물쇠**: 3자리 번호 자물쇠 `432` (물자 보관 상자/봉투 03 해제용).
- **올바른 진행 절차**:
  1. 3중 대조로 복원한 선반 번호 `432`로 물리 자물쇠 상자 03 개방.
  2. 상자 내부에서 키워드 카드 03(`청지기`)과 완료 코드 `STEWARD-03` 회수.
  3. `432`는 물리 자물쇠 전용이므로 웹에 다시 입력하지 않음.
  4. 활동 페이지(`activity.html`)에 완료 코드 `STEWARD-03` 입력해 스테이지 해금.

## 9. 웹 화면 구현 사양 및 상태 전이

### 웹 상태 전이 (State Transitions)
1. `S0_BRIEFING`: 창고 및 물자 보관소 사건 개요 및 역할 배정 안내.
2. `S1_RESTORE`: 원본 선반 안내도 제공 (거룩한 물자 위치 복원 지침).
3. `S2_AUDIT`: 변경 기록 6건 제시 (조작 기록 3건 선택).
4. `S3_ACCUSE`: 범인 지목 화면 (`배급 담당` 선택).
5. `S4_UNLOCK`: 지목 성공 시 인계 표식 순서 `□ → △ → ○` 공개.
6. `S5_COMPLETE`: 상자 개방 확인 및 활동 페이지 코드 입력 안내.

### 오답 피드백 문구
