# 03 식량 장부 — 맡겨진 것을 바꾼 사람

## 1. 스테이지 계약

| 항목 | 확정 내용 |
|---|---|
| 대상 | 대학생, 팀당 4~6명 |
| 목표 시간 | 12~18분(표준 15분) |
| 현장 장소 | 주방 및 인접 공간 |
| 장르 | 현장 수색 / 재고 위치 복원 / 기록 감식 / 용의자 추리 |
| 핵심 질문 | 누가 맡겨진 것을 자기 뜻대로 바꾸었는가? |
| 물리 장치 | 팀별 3자리 자물쇠 상자 또는 봉투 |
| 자물쇠 번호 | `432` |
| 결과 키워드 | `청지기` |
| 완료 코드 | `STEWARD-03` |
| 웹의 역할 | 원본 보관 원칙과 사건 기록을 단계적으로 공개하는 사건 기록 뷰어 |
| 의미 | 청지기는 맡겨진 것을 자기 편의대로 바꾸는 사람이 아니라, 주인의 뜻에 맞게 지키고 설명하는 사람이다. |

이 스테이지에는 덧셈·뺄셈·수량 비교가 없다. 숫자는 복원한 카드의 **선반 위치**에서만 읽는다. 자물쇠를 연 뒤 `432`를 웹에 다시 입력하지 않는다.

## 2. 사건 개요

구호 식량 인계 직전, 세 품목이 지정되지 않은 선반으로 옮겨졌고 장부 문장도 같은 방식으로 고쳐졌다. 네 명의 담당자는 각자 일부 정보만 알고 있다. 팀은 흩어진 재고 카드를 찾아 원래 위치에 놓고, 기록의 문장과 담당별 권한을 대조해 세 건의 조작을 가려낸다. 마지막으로 동일한 표현을 반복한 담당자를 지목하고, 조작된 세 품목의 **원래 선반 번호**를 인계 순서대로 읽어 자물쇠를 연다.

범인은 `배급 담당`이다. 배급 담당은 빠른 배급을 명분으로 보관 위치와 인계 조건을 임의로 바꾸고, 세 변경 기록에만 원본 원칙에 없는 표현인 `먼저 처리`를 남겼다.

## 3. 팀 역할과 정보 분산

웹 시작 화면에서 역할 카드를 한 장씩 맡으라고 지시한다. 4명일 때는 수색 담당이 두 구역을 맡고, 6명일 때는 기록 감식 담당을 두 명으로 나눈다.

| 역할 | 맡는 자료와 행동 | 혼자서는 알 수 없는 것 |
|---|---|---|
| 수색 담당 A | 조리대와 홀수 선반의 재고 카드 3장 회수 | 카드의 원래 위치 |
| 수색 담당 B | 출입구와 짝수 선반의 재고 카드 3장 회수 | 어떤 기록이 조작인지 |
| 보관 복원 담당 | 원본 선반 안내도만 보고 카드 6장 배치 | 사건 기록의 문장 |
| 기록 감식 담당 | 웹의 변경 기록 6건을 소리 내어 읽고 표현 표시 | 현장에서 발견된 카드 위치 |
| 권한 확인 담당 | 네 담당자의 권한표를 보고 가능한 행동 판정 | 카드와 기록의 일치 여부 |
| 반증·발표 담당 | 팀 의견을 `사실 / 추론 / 결론`으로 정리해 최종 선택 | 다른 역할이 가진 원자료 |

자료를 휴대폰 한 대에 몰아 보지 않도록, 웹은 “복원 담당에게 안내도를 보여 주십시오”, “감식 담당만 다음 기록을 읽으십시오”처럼 인계 문구를 표시한다. 최종 지목 전에는 최소 세 역할의 확인 체크가 필요하다.

## 4. 현장 준비물

### 팀별 키트(5세트 동일 제작)

- 역할 카드 6장
- 흑백 재고 카드 6장: `밀`, `기름`, `소금`, `콩`, `건과일`, `물`
- A3 또는 A4 2장 연결형 선반 매트 1개: 선반 `1`~`6`
- 담당별 권한표 1장
- `432`로 잠근 상자 또는 자물쇠 봉투 1개
- 상자 안 결과 카드 1장: 앞면 `청지기`, 뒷면 `STEWARD-03`
- 팀 표식 1세트: `A`~`E` 중 하나. 모든 카드·매트·상자에 같은 팀 표식을 넣는다.

### 현장 배치

- 재고 카드의 실제 발견 위치는 `밀=조리대`, `기름=출입구`, `소금=조리대`, `콩=선반 5`, `건과일=선반 1`, `물=선반 6`으로 고정한다. 정상 품목은 원래 선반에서, 조작 품목만 선반 밖에서 발견되어야 한다.
- 카드를 숨기지 말고 눈높이~허리 높이의 서로 다른 지점에 둔다. 찾는 시간보다 **발견 위치를 기록하는 것**이 중요하다.
- 카드 앞면에는 품목, 발견 위치 칸, 인계 표식만 둔다. 원래 선반 번호는 인쇄하지 않는다.
- 다섯 팀의 카드가 섞이지 않도록 카드 모서리에 팀 문자와 서로 다른 흑백 테두리 패턴(실선, 점선, 이중선, 사선, 물결선)을 함께 쓴다.
- 공간이 좁으면 팀별 출발 지점을 30초 간격으로 나누되, 모든 팀이 독립 키트를 사용하므로 풀이 순서는 서로 영향을 주지 않는다.

## 5. 참가자에게 제공할 정확한 단서

### 5.1 재고 카드 6장

각 카드에는 아래의 품목명과 인계 표식만 크게 인쇄한다. 인계 표식은 숫자가 아니라 도형이며 흑백으로 구분한다.

| 품목 | 인계 표식 | 실제 발견 위치 |
|---|---|---|
| 밀 | ○ | 조리대 |
| 기름 | △ | 출입구 |
| 소금 | □ | 조리대 |
| 콩 | ◇ | 선반 5 |
| 건과일 | ☆ | 선반 1 |
| 물 | + | 선반 6 |

카드 하단 공통 문구: `발견한 자리를 말로 기록하라. 이 자리가 원래 자리라고 단정하지 말라.`

### 5.2 웹 화면 A — 봉인 전 원본 선반 안내도

웹에는 다음 여섯 문장을 번호가 아닌 위치 관계로 제시한다. 복원 담당은 문장을 이용해 카드를 선반 매트에 놓는다.

1. `물은 가장 아래 선반에 둔다.`
2. `콩은 물 바로 위에 둔다.`
3. `소금은 콩 바로 위에 둔다.`
4. `기름은 소금 바로 위에 둔다.`
5. `밀은 기름 바로 위에 둔다.`
6. `건과일은 가장 위 선반에 둔다.`

선반 매트는 위에서 아래로 `1, 2, 3, 4, 5, 6`이다. 따라서 원래 배치는 `1 건과일 / 2 밀 / 3 기름 / 4 소금 / 5 콩 / 6 물`이다. 참가자는 숫자를 계산하지 않고 카드 위치를 복원한다.

### 5.3 인쇄물 — 담당별 권한표

| 담당 | 맡겨진 권한 | 금지된 행동 | 진술 |
|---|---|---|---|
| 보관 담당 | 봉인 전 선반 배치 | 장부 문장 수정 | “원본 안내도대로 여섯 자리를 채웠다.” |
| 장부 담당 | 인계 완료 뒤 문장 확정 | 혼자 위치 변경 | “`확인 뒤 인계`가 원래 문장이다.” |
| 열쇠 담당 | 두 사람 입회 때 창고 개방 | 카드·장부 단독 변경 | “봉인 뒤에는 혼자 문을 연 적이 없다.” |
| 배급 담당 | 확정된 장부대로 전달 | 위치·조건 임의 변경 | “급한 품목은 먼저 처리해도 된다고 판단했다.” |

권한표 하단: `선의나 속도는 맡겨진 권한을 바꾸지 않는다. 위치와 문장을 함께 바꿀 수 있다고 주장한 사람이 있었는지 확인하라.`

### 5.4 웹 화면 B — 변경 기록 6건

웹은 아래 기록을 섞어서 카드 형태로 보여 준다. 각 기록에는 `품목 / 발견 위치 / 기록 문장 / 기록자`가 있다. “발견 위치”는 수색 담당이 실제 카드를 찾은 구역과 일치해야 한다.

| 인계 표식 | 품목 | 발견 위치 | 기록 문장 | 기록자 | 판정 |
|---|---|---|---|---|---|
| ○ | 밀 | 조리대 | `먼저 처리 — 조리대로 이동` | 배급 담당 | 조작 |
| △ | 기름 | 출입구 | `먼저 처리 — 출입구로 이동` | 배급 담당 | 조작 |
| □ | 소금 | 조리대 | `먼저 처리 — 조리대로 이동` | 배급 담당 | 조작 |
| ◇ | 콩 | 선반 5 | `확인 뒤 인계 — 원래 자리 유지` | 장부 담당 | 정상 |
| ☆ | 건과일 | 선반 1 | `확인 뒤 인계 — 원래 자리 유지` | 보관 담당 | 정상 |
| + | 물 | 선반 6 | `확인 뒤 인계 — 원래 자리 유지` | 열쇠 담당 | 정상 |

세 조작 기록은 다음 세 근거가 모두 겹친다.

- 원본 장부 문장 `확인 뒤 인계`가 아닌 `먼저 처리`를 쓴다.
- 원래 선반이 아니라 발견 구역으로 옮겼다고 적혀 있다.
- 위치와 인계 조건을 바꿀 권한이 없는 `배급 담당`이 기록했다.

정상 기록에도 발견 구역과 같은 품목이 있어 “출입구에서 찾았다”만으로는 조작을 고를 수 없다. 반드시 위치 복원, 문장 비교, 권한표를 함께 사용해야 한다.

### 5.5 웹 화면 C — 사건 결론

웹 질문: `맡겨진 위치와 인계 원칙을 자기 판단으로 바꾼 담당자는 누구인가?`

선택지: `보관 담당 / 장부 담당 / 열쇠 담당 / 배급 담당`

- 오답: 근거별 피드백만 주고 정답을 공개하지 않는다.
- 정답 `배급 담당`: `결론은 맞습니다. 이제 조작된 세 품목을 인계 표식 순서로 확인하십시오.`를 표시한다.

인계 표식 순서는 웹에 `□ → △ → ○`로 표시한다. 해당 품목은 `소금 → 기름 → 밀`이고, 복원된 원래 선반 번호는 `4 → 3 → 2`이다.

## 6. 자물쇠 번호 `432` 산출 규칙

최종 세 조작 품목은 `소금`, `기름`, `밀`이다. 세 기록의 기록자와 문구는 모두 `배급 담당 / 먼저 처리`로 동일하다. 웹이 공개하는 인계 표식 순서는 `□ → △ → ○`, 즉 `소금 → 기름 → 밀`이다.

따라서 복원 매트에서 카드가 놓인 선반 번호를 순서대로 읽으면 `4-3-2`가 된다. 참가자는 수량을 세거나 부족분을 계산하지 않는다.

자물쇠를 열면 상자 안에서 `청지기 / STEWARD-03` 카드를 얻는다. 웹에는 `상자를 열었다` 버튼만 두며, 버튼을 누르면 “결과 카드를 활동 페이지에 기록하십시오”라고 안내한다. 웹에 `432`를 입력하는 칸은 만들지 않는다.

| 1:30~4:00 | 두 구역에서 팀 표식이 맞는 재고 카드 6장 회수, 발견 위치 구두 공유 | 카드는 쉽게 보이게 배치 |

## 8. 웹 상태와 필요한 문구

### 상태

1. `briefing`: 사건 설명과 역할 배정
2. `search`: 카드 6장 발견 체크(정답 입력이 아니라 누락 방지용)
3. `restore`: 원본 안내도 표시, 복원 완료 자기 확인
4. `audit`: 변경 기록 6건에서 의심 기록 3건 선택
5. `accuse`: 담당자 선택과 근거 체크
6. `unlock`: 인계 표식 `□ → △ → ○` 공개
7. `complete`: 상자 개방 확인과 활동 페이지 안내

새로고침 시 `briefing` 이후 현재 상태와 선택한 의심 기록을 로컬 상태에 보존한다. 관리자는 QR 없이 모든 상태를 미리 볼 수 있어야 한다.

### 오답·실패 피드백

- 의심 기록이 3건이 아닐 때: `사라진 것은 세 건입니다. 같은 표현이 반복된 기록부터 찾으십시오.`
- 정상 기록을 포함했을 때: `발견 장소만으로 판단하지 마십시오. 원래 선반, 문장, 권한이 모두 어긋나는지 확인하십시오.`
- 범인 오답: `그 담당자에게 위치와 인계 문장을 함께 바꿀 기회가 있었습니까? 권한표와 서명을 다시 대조하십시오.`
- 자물쇠가 열리지 않을 때 웹 안내: `현재 발견 장소가 아니라, 복원 매트의 원래 선반 번호를 읽으십시오.`

## 9. 단계별 힌트

- 힌트 1 — 시선: `카드가 발견된 곳과 원래 있어야 할 곳은 다를 수 있습니다. 먼저 여섯 장을 원본 안내도대로 복원하십시오.`
- 힌트 2 — 대조: `조작된 기록에는 같은 두 단서가 반복됩니다. “먼저 처리”라는 문장과 그 문장을 쓴 담당자를 권한표에서 확인하십시오.`
- 힌트 3 — 행동: `소금, 기름, 밀 카드를 매트에서 찾고, 웹의 표식 순서 □ → △ → ○대로 선반 번호를 읽으십시오.`

진행자는 힌트 사이에 최소 60초를 두고, 힌트 3에서도 숫자 `432`를 직접 말하지 않는다.

## 10. 흑백 인쇄 규격

- 정보 구분에 색을 사용하지 않는다. 팀은 문자+테두리 패턴, 품목은 이름+도형 표식을 함께 사용한다.
- 본문 최소 11pt, 품목명과 선반 번호 최소 20pt, 표식 최소 24pt로 제작한다.
- 회색 면 채우기는 20% 이하로 제한하고, 핵심 칸은 1.5pt 이상의 검정 테두리를 쓴다.
- 카드 뒷면에도 팀 문자를 넣어 뒤집히거나 섞여도 복구할 수 있게 한다.
- `6`과 `9`, `1`과 `7`처럼 혼동하기 쉬운 숫자는 사용하지 않으며, 최종 번호는 매트에 인쇄된 `4`, `3`, `2`를 그대로 읽는다.
- QR은 최소 30mm 정사각형, 주변 여백 4모듈 이상을 확보한다.

## 11. 5팀 동시 운영

- A~E 다섯 팀에 완전한 독립 키트와 독립 자물쇠를 제공한다. 공유 카드나 선착순 단서는 없다.
- QR은 하나를 공유해도 되지만 팀별 진행 상태는 브라우저 로컬 상태로 분리한다.
- 카드 수색 구역은 같되 팀별 테두리 패턴을 사용하고, 각 팀의 카드 위치를 30~50cm씩 어긋나게 둔다.
- 진행자는 중앙에서 다섯 선반 매트와 상자의 상태를 한눈에 볼 수 있게 배치한다.
- 팀 간 번호 유출에 대비해 “번호만 들었으면 근거를 설명해야 상자를 받을 수 있다”는 운영 규칙을 적용한다. 진행자는 `복원 위치 3개 + 조작 문구 + 담당자` 설명을 들은 뒤 해당 팀 상자를 건넨다.
- 상자를 고정 배치할 경우 팀 문자가 맞는 자물쇠만 열도록 안내한다.

## 12. 진행자 정답표

| 검수 항목 | 정답 |
|---|---|
| 원래 선반(위→아래) | 건과일 / 밀 / 기름 / 소금 / 콩 / 물 |
| 조작된 품목 | 소금 / 기름 / 밀 |
| 반복된 조작 문구 | `먼저 처리` |
| 범인 | 배급 담당 |
| 번호 읽기 순서 | □ 소금 → △ 기름 → ○ 밀 |
| 선반 번호 | `4 → 3 → 2` |
| 자물쇠 | `432` |
| 키워드 | `청지기` |
| 완료 코드 | `STEWARD-03` |

성공 설명: `배급 담당은 빠르게 나누려는 자기 판단으로 맡겨진 위치와 인계 원칙을 바꾸었습니다. 여러분은 수량을 맞춘 것이 아니라, 원래 뜻대로 자리를 복원하고 변경의 책임을 밝혔습니다. 맡은 것을 주인의 뜻대로 지키고 설명하는 사람이 청지기입니다.`

## 13. 플레이테스트 및 인수 기준

### 문서 기반 드라이런 결과

- 원본 안내 문장만으로 여섯 카드의 위치가 하나로 결정된다.
- 조작 기록은 `원래 위치 불일치 + 문장 불일치 + 권한 위반`의 세 근거가 겹쳐 찍기로 고르기 어렵다.
- 최종 번호는 수량 계산 없이 카드 위치와 표식 순서만으로 `432`가 된다.
- 물리 자물쇠 뒤에는 결과 코드만 있어 웹 중복 입력이 없다.
- 다섯 팀은 독립 키트를 사용하므로 카드 선점 없이 동시에 운영할 수 있다.

### 현장 플레이테스트 체크리스트

- [ ] 대학생 4~6명이 설명 없이 18분 안에 완료한다.
- [ ] 모든 팀원이 최소 한 번 자료를 읽거나 카드를 옮기거나 근거를 말한다.
- [ ] 참가자가 수량 계산을 시도하지 않고 선반 위치를 사용한다.
- [ ] `배급 담당` 지목 전에 세 종류의 근거를 말할 수 있다.
- [ ] 흑백 복사본에서 팀 테두리와 도형 표식이 구분된다.
- [ ] 5팀 동시 수색 때 카드가 섞이거나 한 팀이 다른 팀의 카드를 가져가지 않는다.
- [ ] 잘못된 기록 3개 선택, 잘못된 범인 선택, 새로고침 상태를 각각 확인한다.
- [ ] `432` 개방 후 웹이 같은 번호를 요구하지 않는다.

## 14. 구현·인쇄물 담당 인계 사항

- 웹 담당: 5.4의 기록 데이터를 그대로 사용하고, 의심 기록 3개 선택과 범인 선택을 분리한다.
- 인쇄물 담당: 팀별 6장씩 총 30장의 재고 카드, 역할 카드 30장, 선반 매트 5장을 제작한다.
- 운영 담당: 팀별 상자 안에 `청지기 / STEWARD-03` 카드가 있는지 시작 전과 회차 종료 후 확인한다.
- PM 담당: 기존 수량·부족분 계산 문구를 웹과 통합 출력물에서 제거하고, 자물쇠·키워드·완료 코드 계약은 유지한다.
