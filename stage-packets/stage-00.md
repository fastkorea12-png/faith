# 00 본관 스테이지 패키지 — 조작된 사건파일

## 1. 스테이지 계약

| 항목 | 확정 내용 |
|---|---|
| 대상 | 대학생, 팀당 3~6명 (총 5팀 동시 진행) |
| 목표 시간 | 12~15분 (오프닝 브리핑 및 사건 진입 포함 20분) |
| 현장 장소 | 본관 접수대 및 중앙 로비 |
| 장르 | 오프닝 사건 브리핑 / 문서 추리 / 모순 감식 |
| 핵심 질문 | 이미 본관에 도착했으나 최종 목적지가 미기록된 우리는 누구인가? |
| 물리 장치 | 물리 자물쇠 없음 (오프닝 단계, 웹 거짓 기록 3건 지목 및 정체성 입력) |
| 웹 기록 감식 정답 | 거짓 기록 3건 선택 (`stampA` 도장 기록, `deskC` 접수대 기록, `numberD` 사건 번호 기록) |
| 정체성 웹 입력 | `나그네` |
| 결과 키워드 | `나그네` (키워드 카드 00 수령) |
| 완료 코드 | `PILGRIM-00` (활동 페이지 입력) |
| 핵심 의미 | 본관은 최종 목적지가 아닌 출발/접수 지점임을 깨닫고, 세상의 도착 명단에서 벗어나 "아직 길 위에 있는 나그네"로서의 첫 정체성을 확립한다. |

`나그네`, `PILGRIM-00`은 각각 용도가 다르다. `나그네`는 팀이 회수할 키워드 카드이며, `PILGRIM-00`만 활동 페이지(`activity.html`)에 입력한다.

---

## 2. 플레이어 경험과 사건 개요

참가자는 본관 접수대에서 00 사건파일 봉투를 수령한다. 접수 메모와 접수 기록 5건이 제공된다.

**현장 사건 메모 (CASE H-11-13)**:
- 접수 시각: `11:13`
- 조사팀 상태: `미도착`
- 현재 위치: `본관 접수대`
- 최종 목적지: `미기록`
- 단서 문구:
  - 도착한 팀은 접수 명단에서 사라진다.
  - 아직 길 위에 있는 팀만 이름을 남긴다.
  - 기록자는 사건번호 앞의 **H**를 지우지 말라고 했다.
  - 11:13은 시간이 아니라, 기록을 여는 위치다.
  - 본관은 목적지가 아니라 접수 지점이다.

**접수 기록 5건 카드 텍스트 & 진위 여부**:
1. `stampA` (도장 기록): "조사팀은 11:13에 목적지 본향 도착 확인 도장을 받았다." — **거짓 (false)**
2. `listB` (명단 기록): "미도착 명단에는 아직 길 위에 있는 조사팀의 이름만 남는다." — **진짜 (true)**
3. `deskC` (접수대 기록): "본관 접수대는 조사팀의 최종 목적지로 등록되었다." — **거짓 (false)**
4. `numberD` (사건 번호 기록): "사건 번호 H-11-13의 H는 오기이므로 지워도 된다." — **거짓 (false)**
5. `timeE` (시각 기록): "11:13은 조사팀이 도착한 시각이 아니라, 기록을 여는 위치다." — **진짜 (true)**

사건 메모와 어긋나는 거짓 기록 3건(`stampA`, `deskC`, `numberD`)을 가려내어 웹 화면(`game.html?stage=case`)에서 확정하면 정체성 입력창이 열린다.

사건번호 H-11-13은 히브리서 11장 13절("또 땅에서는 나그네와 외국인임을 증언하였으니")을 가리키며, 정체성 입력창에 `나그네`를 입력하면 완료 코드 `PILGRIM-00`을 획득한다.

## 3. 팀 분업 구조 (5팀 동시 운영)

5개 팀(A~E조)이 본관 접수대에서 동시에 시작하므로 역할을 분담하여 조작된 문서들을 빠르게 검증한다.

| 역할 | 담당 행동 | 반드시 공유할 정보 |
|---|---|---|
| 사건 기록관 | 웹 화면 접속 및 접수 메모(CASE H-11-13) 단서 낭독 | 접수시각 11:13, H 보존, 미도착/접수지점 조건 |
| 접수 기록 감식관 | 접수 기록 5건(stampA~timeE)의 진위 대조 | 사건 메모와 모순되는 거짓 기록 3건 (`stampA`, `deskC`, `numberD`) |
| 구절 해독관 | 사건번호 H-11-13과 히브리서 11:13 연계 해독 | 위치 지표 `11:13` 및 성경적 명칭 |
| 정체성 선언 담당 | 팀 토론 마감 및 웹 거짓 기록 확정 후 정체성 입력 | 거짓 3건 확정 후 최종 정체성 단어 (`나그네`) |

| 조작된 접수기록 인쇄물 | 5부 | A4 220g 켄트지 (현장 사건 메모 포함) | 봉투 내부 삽입 |

| 키워드 카드 00 (`나그네`) | 5장 | A4 220g 켄트지 (앞면 `나그네`, 뒷면 `00 / PILGRIM-00`) | 진행자 중앙 보관함 |

## 6. QR 배치 및 현장 구성

- **배치 위치**: 본관 메인 접수대 중앙 및 로비 기둥
- **부착 형태**: A4 스탠드 패널 및 벽면 눈높이 부착
- **QR 접속 URL**: `game.html?stage=case` (QR 스캔 시 바로 00 본관 미션 진입)
- **현장 동선**: 5개 팀이 동시 진입하므로 접수대에서 봉투 및 클립보드를 수령한 후 로비 내 테이블/의자로 분산하여 대조 작업 진행.

## 7. 자물쇠 및 정답 처리 (Lock & Answer Handling)

- **물리 자물쇠**: 없음 (오프닝 단계로 실물 자물쇠는 01 야외부터 시작함).
- **정답 처리 프로세스**:
  1. 실물 00 사건파일 문서(현장 사건 메모)와 접수 기록 5건(`stampA`~`timeE`) 대조.
  2. 웹 화면(`game.html?stage=case`) 접속 후 사건 메모와 어긋나는 거짓 기록 3건 (`stampA` 도장 기록, `deskC` 접수대 기록, `numberD` 사건 번호 기록)을 선택하고 `[거짓 기록 3건 확정]` 클릭.
  3. 거짓 기록 3건 확정 시 열리는 정체성 입력창에 `나그네` 입력 후 `[정체성 확인]` 클릭.
  4. 정답 확인 시 히브리서 11:13 구절 패널("또 땅에서는 나그네와 외국인임을 증언하였으니") 출력 및 완료 코드 `PILGRIM-00` 공개.
  5. 팀은 진행자에게 완료 코드를 제시하고 실물 키워드 카드 00 (`나그네`) 수령.
  6. 활동 페이지(`activity.html`)에 `PILGRIM-00`을 입력하여 00 스테이지 공식 해금 처리.

## 8. 진행자 3단계 힌트 (3 Hint Tiers)

1. **시선 (Tier 1)**: "현장 사건 메모의 조건(목적지 미기록, 접수대=접수 지점, H 지우지 말 것, 11:13=위치)과 접수 기록 5건을 대조하십시오. 서로 어긋나는 거짓 기록 3건을 찾으세요."
2. **대조 (Tier 2)**: "도장 기록(stampA: 도착 도장 받음), 접수대 기록(deskC: 최종 목적지 등록), 사건 번호 기록(numberD: H 지워도 됨)이 거짓 기록 3건입니다. 이 3건을 웹에서 선택하여 확정하세요."
3. **행동 (Tier 3)**: "거짓 기록 3건을 확정하면 진짜 기록(listB: 미도착 명단 남음, timeE: 11:13은 기록을 여는 위치)만 남습니다. 사건번호 H-11-13은 히브리서 11장 13절('땅에서는 나그네와 외국인임을 증언하였으니')을 의미합니다. 정체성 입력창에 '나그네'를 입력하십시오."

## 9. 회차별 리셋 체크리스트 (Reset Checklist)

- [ ] 5개 사건파일 봉투에 현장 사건 메모 1부, 접수 기록 카드 5장(`stampA`~`timeE`), 시간표 1장, 지도 조각 1장, 모순 체크 보드 1장이 완비되어 있는지 확인.
- [ ] 클립보드 5개 및 모나미 볼펜 10자루가 정위치에 배치되어 있는지 확인.
- [ ] 진행자 보관함에 실물 키워드 카드 00(`나그네`) 5장이 준비되어 있는지 확인.
- [ ] 모순 체크 보드 필기 흔적 제거 또는 새 서식으로 교체.
- [ ] 웹 테스트 기기 새로고침 및 브라우저 입력 초기화 확인.

## 11. 공용 물품 및 공유 자원 운영안 (Shared Inventory)

- **공용 자원**: 본관 QR 안내판 2개 및 진행자 중앙 보관함.
- **키워드 카드 분배**: 팀이 완료 코드 `PILGRIM-00`을 진행자에게 제시하면 진행자가 중앙 보관함에서 키워드 카드 00(`나그네`)을 지급함.
- **대기열 조율**: 5개 팀이 동시에 스타트할 경우 접수대 병목을 막기 위해 A~E조 수령 간격을 30초씩 부여.
