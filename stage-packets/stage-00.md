# 00 본관 스테이지 패키지 — 조작된 사건파일

## 1. 스테이지 계약

| 항목 | 확정 내용 |
|---|---|
| 대상 | 대학생, 팀당 3~6명 (총 5팀 동시 진행) |
| 목표 시간 | 12~15분 (오프닝 브리핑 및 사건 진입 포함 20분) |
| 현장 장소 | 본관 접수대 및 중앙 로비 |
| 장르 | 오프닝 사건 브리핑 / 문서 추리 / 모순 감식 |
| 핵심 질문 | 이미 본관에 도착했으나 최종 목적지가 미기록된 우리는 누구인가? |
| 물리 장치 | 물리 자물쇠 없음 (오프닝 단계, 웹 정체성 입력 및 실물 사건파일 대조) |
| 정체성 웹 입력 | `나그네` |
| 결과 키워드 | `나그네` (키워드 카드 00 수령) |
| 완료 코드 | `PILGRIM-00` (활동 페이지 입력) |
| 핵심 의미 | 본관은 최종 목적지가 아닌 출발/접수 지점임을 깨닫고, 세상의 도착 명단에서 벗어나 "아직 길 위에 있는 나그네"로서의 첫 정체성을 확립한다. |

`나그네`, `PILGRIM-00`은 각각 용도가 다르다. `나그네`는 팀이 회수할 키워드 카드이며, `PILGRIM-00`만 활동 페이지(`activity.html`)에 입력한다.

---

## 2. 플레이어 경험과 사건 개요

참가자는 본관 접수대에서 00 사건파일 봉투를 수령한다. 접수 기록에는 "사건번호 CASE H-11-13, 접수 시각 11:13, 조사팀 상태 미도착, 최종 목적지 미기록"이 적혀 있다.

함께 제공되는 진술서 카드 5장, 시간표 카드, 지도 조각을 대조하면 서로 시간이 맞지 않는 **거짓 기록 3건**이 발견된다.
1. 도착한 자는 접수 명단에서 지워진다.
2. 거짓 기록을 제거하고 남은 진짜 기록은 "아직 길 위에 있는 조사팀"만을 가리킨다.
3. 사건번호 H-11-13은 히브리서 11장 13절("땅에서는 나그네와 외국인임을 증언하였으니")의 힌트가 되어 정체성이 `나그네`임을 입증한다.

웹 화면(`game.html?stage=case`)의 질문 "아직 목적지에 이르지 않은 조사팀의 정체성"에 `나그네`를 입력하면 히브리서 성경 패널이 열리며 완료 코드 `PILGRIM-00`을 획득한다.

## 3. 팀 분업 구조 (5팀 동시 운영)

5개 팀(A~E조)이 본관 접수대에서 동시에 시작하므로 역할을 분담하여 조작된 문서들을 빠르게 검증한다.

| 역할 | 담당 행동 | 반드시 공유할 정보 |
|---|---|---|
| 사건 기록관 | 웹 화면 접속 및 접수 메모(CASE H-11-13) 낭독 | 접수시각 11:13, "H"의 의미, 미도착 상태 |
| 진술서 감식관 | 진술서 카드 5장의 날짜·시간·장소 대조 | 모순되는 거짓 진술 3건의 번호 |
| 시간표 대조관 | 시간표 카드와 지도 조각의 동선 비교 | 실제 이동 가능 시각과 불가능 시각 |
| 정체성 선언 담당 | 팀 토론 마감 및 웹 정체성 입력 | 최종 정체성 단어 (`나그네`) |

## 6. QR 배치 및 현장 구성

- **배치 위치**: 본관 메인 접수대 중앙 및 로비 기둥
- **부착 형태**: A4 스탠드 패널 및 벽면 눈높이 부착
- **QR 접속 URL**: `game.html?stage=case` (QR 스캔 시 바로 00 본관 미션 진입)
- **현장 동선**: 5개 팀이 동시 진입하므로 접수대에서 봉투 및 클립보드를 수령한 후 로비 내 테이블/의자로 분산하여 대조 작업 진행.

---

## 7. 자물쇠 및 정답 처리 (Lock & Answer Handling)

- **물리 자물쇠**: 없음 (오프닝 단계로 실물 자물쇠는 01 야외부터 시작함).
- **정답 처리 프로세스**:
  1. 실물 00 사건파일 문서 및 진술서 모순 대조.
  2. 웹 화면(`game.html?stage=case`) 접속 후 "아직 목적지에 이르지 않은 조사팀의 정체성" 확인.
  3. 정체성 입력창에 `나그네` 입력.
  4. 정답 확인 시 히브리서 11:13 구절 패널 출력 및 완료 코드 `PILGRIM-00` 공개.
  5. 팀은 진행자에게 완료 코드를 제시하고 실물 키워드 카드 00 (`나그네`) 수령.
  6. 활동 페이지(`activity.html`)에 `PILGRIM-00`을 입력하여 00 스테이지 공식 해금 처리.

## 8. 진행자 3단계 힌트 (3 Hint Tiers)

1. **시선 (Tier 1)**: "접수 메모의 시각(11:13)과 진술서 카드들의 시간을 대조해 보십시오. 서로 시간이 맞지 않는 거짓 진술 3개를 먼저 고르세요."
2. **대조 (Tier 2)**: "거짓 진술을 제외하면 진짜 기록만 남습니다. 접수 명단에서 도착한 자는 지워지고, 최종 목적지가 미기록인 채 길 위에 남은 자를 가리키는 성경적 명칭을 생각하십시오."
3. **행동 (Tier 3)**: "H-11-13은 히브리서 11장 13절('땅에서는 나그네와 외국인임을 증언하였으니')을 의미합니다. 웹 입력창에 '나그네'를 입력하십시오."

## 9. 회차별 리셋 체크리스트 (Reset Checklist)

- [ ] 5개 사건파일 봉투에 조작된 접수기록 1부, 진술서 카드 5장, 시간표 1장, 지도 조각 1장, 모순 체크 보드 1장이 완비되어 있는지 확인.
- [ ] 클립보드 5개 및 모나미 볼펜 10자루가 정위치에 배치되어 있는지 확인.
- [ ] 진행자 보관함에 실물 키워드 카드 00(`나그네`) 5장이 준비되어 있는지 확인.
- [ ] 모순 체크 보드 필기 흔적 제거 또는 새 서식으로 교체.
- [ ] 웹 테스트 기기 새로고침 및 브라우저 입력 초기화 확인.

## 11. 공용 물품 및 공유 자원 운영안 (Shared Inventory)

- **공용 자원**: 본관 QR 안내판 2개 및 진행자 중앙 보관함.
- **키워드 카드 분배**: 팀이 완료 코드 `PILGRIM-00`을 진행자에게 제시하면 진행자가 중앙 보관함에서 키워드 카드 00(`나그네`)을 지급함.
- **대기열 조율**: 5개 팀이 동시에 스타트할 경우 접수대 병목을 막기 위해 A~E조 수령 간격을 30초씩 부여.
